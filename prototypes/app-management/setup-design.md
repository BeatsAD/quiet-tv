# 首次设置与长期极简体验原型

2026-10-18。设计阶段独立网页原型，未改 Android 原生实现或电视状态。

## 设计依据

沿用 `qa/source-home.png` 与现有原生管理页：海岸壁纸、黑灰静态半透明面板、大面积留白、系统中文字体、细线图标、白色焦点描边。首页的时间日期、四位置 Dock 和胶囊快捷入口延续既有视觉。原型的场景切换器和模拟按钮放在电视画面外。

默认桌面和系统精简分开：支持标准 HOME 选择时，用户先获得桌面体验；需要管理预装软件时再连接。预装应用首选可逆禁用，卸载为单个应用的明确选择。保护项和未适配固件保持只读。

## 页面与交互

| 页面 | 主操作 | 可跳过或恢复 |
| --- | --- | --- |
| 欢迎 | 开始设置 | 先体验桌面 |
| 默认桌面 | 系统选择，或转入 ADB 连接 | 稍后设置；保留原厂桌面 |
| 连接授权 | 传统 TCP 引导与授权，或六位配对码 | 取消、重试、稍后再说；高级端口设置折叠 |
| 应用整理 | 自定义需要禁用的演示应用，确认清单后执行 | 每项可改为保留；整步可跳过 |
| 完成 | 检查默认桌面、精简结果与恢复入口 | 继续管理应用 |
| 极简桌面 | 四个常用应用，应用管理与设置 | 默认桌面状态提示 |
| 应用管理 | 搜索、筛选、单应用禁用／启用／卸载／恢复安装 | 取消默认聚焦；系统保护只读 |
| 恢复中心 | 切回原桌面、重新启用本次禁用项、查看记录 | 不宣称卸载数据可恢复 |

四种情境只模拟路径，不代表真实设备支持：标准切换、传统 ADB、无线配对、暂未适配。无线配对成功后直接继续，不额外模拟传统 RSA 授权弹窗；传统 TCP 连接展示允许／拒绝。暂未适配时提供试用桌面和后续电脑辅助说明，预装应用保持只读。

## 状态与边界

- 演示包名统一使用 `demo.quiet.*`，系统应用用途与精简建议为示例；不可用作真实机型禁用清单。
- 当前页面没有连接 API、ADB 调用、真实卸载和远程服务。设置按钮展示引导说明，应用启动显示演示反馈。
- 浏览器存储保留模拟状态与设置进度。模拟重启仅保留配置并断开模拟连接，不模拟真实启动时间。
- 未添加性能提升百分比、开机广告去除或永久生效承诺。
- 旧版管理原型保留独立入口及状态，不将本次设计自动套用到 Android。

## 验收

已在本地浏览器进行以下交互检查，并保存实际渲染截图：

- 标准切换：选择 Quiet TV、继续整理、连接授权、自定义精简名单、确认取消与再次执行、完成页与首页。
- 传统 ADB：连接失败说明、拒绝授权、重新连接、授权成功后设置默认桌面。
- 无线配对：空配对码校验、六位演示码配对、配对成功后继续、刷新后保留情境与续办目标。

- 键盘：方向键、Enter、Esc、弹窗默认聚焦取消、Shift+Tab／Tab 保持弹窗内、关闭后焦点回到触发位置。
