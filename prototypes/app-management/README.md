# Quiet TV 设置与应用管理交互原型

用于确认视觉、布局和遥控交互；与 Android 原生应用独立。

## 首次设置与长期使用

默认入口 `/` 为新增设置体验，设计说明和验收记录见 [setup-design.md](setup-design.md)。旧版应用管理原型保留在 `/?prototype=management`，也可从页面底部进入。

- 欢迎 → 默认桌面 → 可选连接授权 → 自定义精简 → 完成 → 极简桌面。
- 应用管理：名称／演示包名搜索、筛选、单应用禁用／启用／卸载／预装恢复、保护项只读；普通用户应用的卸载确认无需先连接。
- 恢复中心：切回原厂桌面、恢复本次禁用项、最近操作；卸载后的数据不作可恢复承诺。
- 四种设备情境：标准切换、传统 TCP ADB、无线配对、暂未适配。切换情境会重新开始该设备的演示。
- 设置进度、默认桌面选择和应用状态仅保存在当前浏览器的演示存储中；可点顶部“重置演示”重新开始。
- “模拟 HOME”和“模拟重启”用于评审：重启模拟保留默认桌面和应用状态、断开管理连接，不是真实电视重启。
- 鼠标、方向键、Enter、Esc 和 Tab 可操作；桌面窗口保持 16:9，窄窗口用于检查内容可达性。

本轮没有实现原生首次向导、无线配对或电脑辅助工具，没有连接电视或验证实际系统切换与包管理。

## 原有应用管理原型

- 应用列表：浏览、搜索、五种筛选、启停与卸载确认、只读保护、页内反馈和操作记录。
- 常用应用：最多四个，添加、替换、移除、排序保存与取消，禁用后保留位置。
- 连接设置：端口输入、模拟断开与连接，断开时仍可编辑常用应用。
- 首页入口：查看新图标、图文整体居中、首页卡片与管理页材质的一致性。
- 鼠标、方向键、Enter、Esc 和 Tab 均可操作；小窗口纵向排版，大窗口保持电视 16:9。

此入口仍使用独立的内存演示数据。刷新页面或“更多 → 重置演示状态”恢复旧版管理演示。

开发预览：`npm install`，然后 `npm run dev -- --host 127.0.0.1 --port 4177 --strictPort`。
