# Quiet TV「关于」单屏设计

状态：此单屏原型已由 Android `AboutActivity`／`AboutView` 按原尺寸实现为原生视图，进入时不启动 WebView。开发与验收见 [开发方案](../../docs/ABOUT_DEVELOPMENT_PLAN.md) 和 [验证记录](../../docs/ABOUT_VERIFICATION.md)；真实电视验收仍单独进行。

## 入口

首页右上角增加“关于”，与信号源、网络、设置并列。当前“设置”直接打开电视系统设置，因此使用独立入口。进入后所有信息在一屏展示，不使用详情弹窗、渠道切换或多级页面。

## 单屏内容

| 位置 | 内容 |
| --- | --- |
| 左侧 | 现有电视图标、Quiet TV、版本 1.1.0、测试版标签。 |
| 右侧上部：开源项目 | github.com/BeatsAD/quiet-tv、仓库二维码。 |
| 右侧中部：联系开发者 | WenBin AI LAB、wenbinailab@gmail.com、微信和公众号原始二维码。 |
| 右侧底部：开源许可与致谢 | MIT 许可链接、tv-vibehack 上游链接、Gathin 署名。 |

删除右侧重复版本入口、问题反馈、宣传语、功能介绍、账号说明及所有详情弹窗。二维码直接可见，不再需要进入联系页面。

## 界面与操作

采用 1920×1080 画布，沿用当前黑色、蓝色光晕和白色焦点边框。左侧约 38%，右侧约 62%；右侧三个信息区域用细线分隔。初始焦点在返回按钮。仓库地址、邮箱为只读文本，没有跳转箭头或选中效果；二维码保持直接可见。右下角不显示操作提示。方向键仅在返回、MIT 许可和上游链接之间移动，确定打开对应内容，返回回到首页“关于”入口。微信与公众号直接使用手机扫描。版本区域不显示构建号及其后的“·”，产品名称末尾的品牌圆点保留。

浏览器原型可点链接，也可用方向键／Enter／Esc／Backspace及画布外的模拟遥控器。仅许可和上游链接可操作；浏览器原型在新标签打开对应链接。顶部评审工具条、模拟遥控器、演示首页的时钟与应用卡片不属于最终关于页面。

正式电视实现仍以手机扫码为主要外部访问方式；电视无浏览器时不阻塞页面展示。完整许可应随 APK 离线打包，浏览器原型通过本地 LICENSE 链接打开文本。此方案没有自动更新或联网版本检查。

## 数据来源与边界

- 名称、图标来自现有 README 与 launcher_icon.xml。
- 原型版本保留设计样例 1.1.0／Debug，不证明电视当前安装版本。正式实现读取当前安装包 PackageInfo 与构建类型。
- 开源地址来自仓库 remote；开发者名称、邮箱来自项目现有联系图与提示词。
- 仓库二维码离线生成；微信和公众号使用用户提供的独立 PNG（assets/wechat.png、assets/official.png），直接完整显示，不再解码整张联系图或按固定坐标裁切。保持原显示尺寸、位置和标签。图片与许可、字体使用仓库相对路径。
- 本次未核验远程仓库可访问性、手机扫码、真实电视遥控器或当前安装包。
- Android 实现包含 AboutActivity／AboutView、HomeActivity 入口与焦点恢复及 Manifest 注册。原生单屏读取当前安装版本，独立二维码随包提供；仅许可正文按需使用离线 WebView，视觉回调确认完整内容可绘制后才显示。

## 预览

从仓库根目录执行：

```sh
python3 -m http.server 4186 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4186/prototypes/about/>，默认显示关于单屏。顶部“首页入口”可体验进入与返回。需要保留仓库资源相对路径，不能只分发单个 HTML。
