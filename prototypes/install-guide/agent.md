# Quiet TV Agent 安装说明草案

本文件随本地安装页原型供设计审阅，尚未作为公开安装说明发布。实际版本与下载包以官方仓库为准。

官方安装指南：https://github.com/BeatsAD/quiet-tv/blob/main/docs/INSTALL.zh-CN.md

兼容范围：https://github.com/BeatsAD/quiet-tv/blob/main/docs/COMPATIBILITY.md

## 安装目标

统一先安装、校验并试用，不修改默认桌面。试用确认可用后，询问用户是否设为默认桌面；只有用户同意后，才按实际固件能力尝试切换。全程保留原桌面，不授权禁用、卸载或精简系统。

## 流程

1. 检查电脑工具与现有 ADB 连接、ADB mDNS 服务，必要时仅在电脑当前局域网扫描常用 ADB 连接端口，不跨网段或进行全端口扫描。结合品牌与可读取的型号识别目标；多个候选或身份不明时列出候选让用户选择，不批量操作。未发现电视时，再指导用户查看网络地址、开启调试或完成无线配对，分别核对配对端口与连接端口。电视授权与配对码由用户现场确认，不绕过授权。连接后核对设备身份，所有后续 ADB 命令显式指定同一目标，不预设用户 ID。
2. 在首次启动或切换前，记录系统、固件、当前用户、原 HOME 候选及真实默认组件和原始启用状态。记录保存在仓库外的私有路径，不上传设备转储、IP、序列号或密钥。
3. 实时读取官方发布资产与兼容说明，按系统、架构及已有安装选择 APK。核对 SHA-256、实际包名、版本、最低 API、签名及覆盖升级条件。签名冲突或降级时停止，不用卸载和清数据解决。
4. 安装后核对实际已安装版本与 APK 哈希，再启动试用。首次打开选择“暂不设置，临时使用”，引导用户在电视上完成授权和验证遥控器、应用及系统入口，不改 HOME。
5. 试用确认可用后，询问用户是否设为默认桌面。用户同意后，优先使用系统选择或应用内设置。ADB 切换前核对当前固件支持的命令及当前用户；操作后读回 HOME，等待用户用真实遥控器验证。用户不同意或固件拒绝时保留原默认桌面，说明仍可手动使用，不添加未知守护或禁用原桌面。
6. 提供依据本机记录的恢复方法。默认 HOME、实体遥控器 HOME、重启、冷开机及待机唤醒分别记录；未验证不能报成功。重启需单独确认，发现或连接设备不代表已授权重启。

## 恢复

先读现状及本机记录，核对原组件和用户。优先使用系统或 Quiet TV 的恢复入口；仅恢复实际发生且有记录的修改，精确恢复原值。保留 Quiet TV 和数据。记录、连接或权限不足时说明缺失条件，不套用其他电视的命令，不恢复出厂。

## 交付
