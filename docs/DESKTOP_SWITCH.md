# 桌面管理与新旧桌面切换

入口为通用设置 → 桌面与启动 → 桌面管理。原“桌面守护”和“切换原桌面”合并，电视弹窗与手机扫码设置网页共用状态、操作能力和执行引擎。首页显示当前主桌面、守护状态、可用桌面和主要切换操作，启用／禁用、运行检查、使用验证和诊断放在更多管理。

## 操作

| 现状 | 进入原桌面 | 切回 Quiet TV |
| --- | --- | --- |
| 原桌面被禁用，直接 HOME 接管 | 核对本机记录后启用原包或组件，暂停接管，调整并读回 HOME，再请求显示原桌面 | 恢复切换前 HOME 和接管配置；可明确选择恢复原禁用状态 |
| 原桌面已启用 | 暂停现有接管并切换到原桌面 | 恢复原有配置，保留原桌面启用 |
| 原桌面观察中转 | 保留原桌面，暂停观察与自动接管 | 恢复原来的中转开关，保留原桌面启用 |
| 已配置的同签名 HOME 代理中转 | 保留系统 HOME 和代理组件，通过现有协议暂停中转 | 恢复原代理配置并核对协议回执，不禁用依赖 |

部分固件的原桌面 HOME 优先级高于 Quiet TV。此时，保留原桌面启用可能无法让 HOME 返回 Quiet TV，界面会明确禁用这一选择。只有本次进入原桌面前已经禁用、且原接管方案不依赖原桌面时，才提供“切回并恢复原禁用状态”。恢复禁用时，先准备 Quiet TV 的 HOME 选择，恢复原包/组件状态，再核对实际 HOME；结果未确认时不继续恢复守护。

切换前没有可核对的原桌面记录、当前 HOME 属于其他桌面、记录与固件/用户不符、存在未识别的独立中转助手时，保留当前状态并提示核对。不会通过此入口禁用任意系统桌面、删除应用数据或改动第三方助手。独立禁用仅对本机精确适配已确认可禁用、可精确恢复且不是接管依赖的原桌面开放。

## 状态与更多管理

“守护中”表示当前路线所需服务或代理已就绪；“系统直接启动”表示 Quiet TV 直接作为 HOME 且不需要守护。主动暂停、缺少授权、服务未连接及状态待核对分别显示，不根据当前前台应用或历史切换阶段判断主桌面。HOME、重启、断电开机、待机唤醒的人工验证结果独立展示，服务连接不会自动记为通过。手机“已同步”只表示连接状态。

独立暂停会保存原守护配置，恢复时沿用原路线。新旧桌面往返切换保留切换前的守护意愿，原先暂停的不会被自动开启。没有可核对的恢复记录时给出核对入口，不重新猜测接管路线。

更多管理可单独启用或禁用已记录的原桌面。禁用前保存包和组件的精确启用数值，恢复时区分系统默认状态 0 和显式启用状态 1。当前正在使用原桌面时，须先切回并核对 Quiet TV，再禁用；中转依赖保持启用。部分固件启用原桌面会影响 HOME，此时仅提供“启用并切换”，不承诺单独启用能保持当前主桌面。Quiet TV 自身不提供应用自禁用。

切换、守护控制及原桌面状态变更使用同一串行队列和应用操作锁。确认后状态变化会拒绝过期操作；断连后只核对现状，不自动重放写入。手机网页沿用现有协议的 desktopSwitch 域，旧的 switch 请求保留原三个动作，新 manage 请求使用电视返回的动作能力和确认版本；verify 只记录用户报告的实际结果，不执行电源操作。

## 权限与恢复

系统包或 HOME 变更复用已授权的本机管理 ADB，使用能力探测确认的当前用户命令。没有所需能力时显示原因，可主动请求电视管理连接及系统调试授权。无需变更包和 HOME 的已配置中转，可按现有协议切换。部分已验证的保留原桌面路径无法通过标准 HOME 查询得到组件，此时只暂停和恢复既有中转，不写入或猜测 HOME。

本机 `setup-state.json` 中的 `desktopSwitch` 保存切换前 HOME、原桌面版本、包及组件的精确启用状态、接管配置标识和相关开关。既有安装及接管恢复记录保留。只恢复本次记录涉及的变更，并读回确认；默认启用状态 0 与显式启用状态 1 分别保留。

切换中断、命令响应不完整或执行失败会保留步骤和待核对状态。传输结果不完整时断开不可信连接，不重放写入；用户重新连接、查看状态并再次确认后，才执行恢复。进程重启和重新扫码可继续查看同一份本机记录。版本、固件、HOME 或接管配置被其他操作改变时不猜测恢复值。

显示请求与实际画面分开报告：包状态、HOME 和接管设置可读回；遥控器 HOME、重启、冷启动、待机唤醒和订阅服务可用性仍需对应厂商真机确认。

## 兼容范围

| 档位 | 共用实现与差异 |
| --- | --- |
| Android 5 及以上 | 共用切换记录、原生弹窗、扫码网页、当前用户状态核对及直接/观察/代理路径；具体写入以固件命令和本机接管记录为准 |
| Android 4.0–4.4 | 共用状态、记录和界面，保留 API18 窗口守护、API19 ADB 守护等既有路径；缺少带用户范围的 HOME 或包状态命令时不执行该写入，并给出原因 |
| 厂商及无 HOME 兼容包 | 沿用已配置的接管路线，禁止禁用中转依赖；不在切换过程中改配另一条路线 |

手机助手 App 属于独立工程，本次同步范围为电视内提供的手机扫码设置网页。
