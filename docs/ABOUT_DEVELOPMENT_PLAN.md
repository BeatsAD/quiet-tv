# 关于功能开发与验收方案

视觉与交互以 `prototypes/about/` 单屏原型为基准，保留 Q 字电视品牌图标、只读仓库／邮箱、三个直接可见的二维码、真实版本与测试／正式标签。不显示构建号、个人网站或右下角操作提示。

## 首次进入卡顿修复

原实现点击“关于”时创建 WebView 并加载 HTML，首次网页引擎初始化占用主线程，随后继续加载和绘制页面。真实电视旧版本日志曾记录首次 Activity 首帧 556 ms、后续 177／185 ms，并出现丢帧；这些记录不是页面完整呈现耗时。

1. `AboutActivity` 首屏改为原生 `AboutView`，进入时不创建或调用 WebView。背景、文字、按钮、品牌图标和二维码在同一个原生视图树中绘制，不再等待 HTML、CSS、JavaScript 和字体请求。
2. 保持 1920×1080 基准画布、等比居中适配、原型中的坐标／字号／字重／颜色；显式设置 Outfit 可变字体字重。移除系统切页淡入，避免短暂叠加首页。
3. 微信和公众号使用用户提供的独立 PNG，在首帧前解码完成。项目二维码使用与原 SVG 模块完全一致的原生矢量图，保留白色静区。名称、版本、测试／正式标记继续读取当前安装包信息。
4. 仅点击 MIT 许可时创建离线 WebView。许可加载期间保留完整关于页；WebView 已挂载但不可见，在 `postVisualStateCallback` 确认完整 DOM 已可绘制后，才整体切换为许可正文。`onPageFinished` 只触发视觉状态检查，不再作为显示完成条件。
5. 许可禁用 JavaScript、网络、文件／content 访问，只允许 APK 内的许可 HTML。返回直接显示原来的原生关于页并恢复 MIT 焦点；取消使旧的视觉回调失效，防止返回后许可又覆盖页面。

## 原有交互

- 首页右上角第四个快捷入口“关于”，保留 ⓘ 图标及返回首页后的第四入口焦点。
- 关于初始焦点为返回按钮。返回下／右进入 MIT；MIT 右进入上游，左／上回返回按钮；上游左回 MIT，上回返回按钮。
- 仓库地址、邮箱不参与焦点导航、不响应点击或确定。微信和公众号扫码，不新增操作。
- 确定仅激活一次，按住不重复打开；返回退出关于。上游链接交给系统浏览器，无浏览器时保留页面与焦点。
- 离线许可可以上下滚动，返回恢复原 MIT 焦点，不重建关于页。

## 文件范围与验证

`AboutActivity.java` 管理原生页、许可和生命周期；`AboutView.java` 按原型布局；`ic_about_back.xml`、`ic_about_source.xml` 与原型矢量一致。原型仍供浏览器评审；构建脚本提供二维码和完整许可的离线资源。

使用专用 `quiet-about-api33`／`emulator-5564` 验证，保护其他模拟器及真实电视。定向构建、lint 和 about instrumentation 检查：首次及重复进入均没有 WebView、真实版本与标签、二维码、只读内容、许可视觉回调与快速取消、外部链接及首页焦点。对比修复前后截图，核对 1080p／720p 等比布局与二维码软件解码。

启动时间记录区分 Activity 首帧、完整原生页报告和测试同步时间。模拟器样本不作为真实电视性能改善百分比；真实电视安装与遥控体验单独验收。本地归档和提交不等于发布或推送。

视觉状态回调约束见 [Android WebView 官方说明](https://developer.android.com/reference/android/webkit/WebView#postVisualStateCallback(long,%20android.webkit.WebView.VisualStateCallback))。
