# 关于功能开发与验收方案

本次按已确认的 `prototypes/about/` 单屏原型执行开发，交互基线为 `54c6c34`，同时保留实施期间已提交的 `eca70e2` Q 字电视品牌图标。已移除个人网站、问题反馈、重复版本入口与详情弹窗，不恢复这些内容。

## 实施步骤

1. 首页右上角扩为四个快捷入口：信号源、网络、设置、关于。增加同尺寸 ⓘ 矢量图标，沿用现有胶囊与白色焦点框；前三项操作不变。
2. 新增 `AboutActivity`。复用原型实际的关于区 HTML、CSS、二维码和焦点代码，通过构建脚本生成随 APK 离线打包的资源，避免另写一套布局造成尺寸、文案或交互偏差。构建时排除评审工具条、模拟遥控器和演示首页。
3. 左侧名称、版本名、测试／正式标记读取当前安装包 `PackageManager` 信息，不使用原型中的硬编码版本，也不以远程最新版替代当前安装版本。
   页面不显示构建号及其后的“·”；保留产品名称末尾的品牌圆点。构建号仅用于安装包内部版本和归档。
4. 右侧仅保留仓库与二维码、WenBin AI LAB／邮箱／微信与公众号二维码、MIT 许可与上游致谢。原始二维码图像及所有样式不重绘。
5. 仓库地址与邮箱只读展示，不参与焦点导航、不响应点击或确定，移除仓库的跳转箭头及右下角操作提示。仅上游项目链接交给系统浏览器打开，无浏览器时保留页面与焦点。MIT 链接打开 APK 内的完整许可文档，返回恢复许可链接焦点。
6. 首页返回定位到“关于”，避免 `loadApps()` 在回到首页时把焦点重置到常用应用。

## 视觉与交互逐项约束

- 1920×1080 基准画布等比适配。左 38%、右 62%，保持图标、产品名称、版本与测试／正式标记、三个右侧区域的坐标、字号、分隔线、二维码与配色。
- 单屏内容静态展示；不新增关于详情层、账号、更新检查或反馈表单。
- 初始焦点：左上角返回按钮。
- 返回按钮下／右方向进入 MIT；MIT 右方向进入上游，左／上方向回到返回按钮；上游左方向回到 MIT，上方向回到返回按钮。仓库地址与邮箱始终跳过。
- 确定仅激活一次，按住不重复打开；返回键退出关于页，首页恢复第四个快捷入口。离线许可正文可上下滚动，返回恢复 MIT 焦点。
- WebView 只显示受控的随包资源，禁用文件／内容访问及网络加载，不暴露 JavaScript 原生对象。链接通过明确目标列表处理；不会把外部网页载入本地内容上下文。

## 验证与交付

1. 构建资源生成检查：只有正式关于页，没有评审控件；全部 CSS、脚本、字体、QR 与许可均可离线读取。
2. 定向编译、必要 lint 与独立 instrumentation。只使用新建的 `quiet-about-api33` / `emulator-5564`，不安装或修改已连接的真实电视与平板。
3. 对比原型画布和模拟器截图，检查单屏无裁切、二维码及信息图标可见、焦点框位置与文本一致。检查不同分辨率的等比布局；字体回退差异如有则记录。
4. 版本断言以模拟器安装包信息为准；检查无浏览器、许可返回、按键与首页焦点。
5. 必要验证通过后创建中文本地提交，归档带版本号 APK，记录哈希与测试结果。不推送、不发布、不操作真实电视。真实电视扫码距离、厂商浏览器可用性及实际遥控器体验单独验收。

采用随包 HTML 的依据：[Android 官方本地 WebView 内容说明](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content)。当前安装版本字段参照 [PackageInfo API](https://developer.android.com/reference/android/content/pm/PackageInfo)。
