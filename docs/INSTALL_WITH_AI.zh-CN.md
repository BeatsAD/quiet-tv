# 使用 AI 安装 Quiet TV

这份提示词用于把随附的 Quiet TV 桌面安装到使用者自己的电视上。将安装包、`SHA256SUMS.txt` 和本文件一起交付；使用者解压后，用能够访问本地文件、执行终端命令的 AI 编程工具打开该文件夹，再复制下方提示词。

本份交付固定为 **1.1.0 / b14 / Debug 测试版**，不随其他版本变化。最低需要 Android 12 / API 31 和电视环境；其他机型的安装、默认桌面切换和原桌面禁用均需逐机验证。Android 11 及以下和非 Android 电视系统不适用。

| 项目 | 本份交付 |
| --- | --- |
| 安装包 | `quiet-tv_1.1.0_b14_debug.apk` |
| 应用名称 | Quiet TV |
| 包名 | `home.quiet.tv` |
| 桌面入口 | `home.quiet.tv/.HomeActivity` |
| SHA-256 | `ec7b21e5e15ffa9f1f90aae03c181b03d7a74993ac2b7eeebf2efe0786dd25b2` |

当前仓库为私密仓库，已有 Release 提供的是旧版测试包。接收者应使用随附 APK，不依赖仓库访问权限，也不把旧版下载替代本份交付。校验值用于核对文件一致性，安装包应由可信的提供者直接交付。

## 复制给 AI 编程工具的提示词

```text
请把当前文件夹中随附的 Quiet TV 桌面安装到我自己的电视上，设为默认桌面，并在确认可用且具备恢复条件后，禁用原桌面。

安装目标已确定：Quiet TV 1.1.0 / b14 / Debug 测试版。
安装包：quiet-tv_1.1.0_b14_debug.apk
包名：home.quiet.tv
桌面入口：home.quiet.tv/.HomeActivity
最低系统：Android 12 / API 31，需具备电视运行环境。
预期 SHA-256：ec7b21e5e15ffa9f1f90aae03c181b03d7a74993ac2b7eeebf2efe0786dd25b2

请使用随附 APK 完成安装。用普通用户能理解的语言沟通；能通过工具完成的操作直接执行，需要我在电视上操作时给出清楚步骤。

一、检查安装包与设备
1. 定位随附 APK，计算 SHA-256，与上述值及 SHA256SUMS.txt 核对，并读取 APK 内的包名、版本和最低系统要求。文件缺失或不一致时先说明问题，不用其他版本代替。
2. 检查电脑系统和 ADB。缺少工具时，使用官方 Android SDK Platform-Tools，并按当前电脑系统配置。
3. 指导我开启电视实际支持的调试方式并完成电视端授权。根据设备能力选择 USB、传统网络 ADB 或配对调试；不要预设端口、设备地址或用户 ID。
4. 确认目标电视及当前用户，多台设备连接时先让我选择。后续命令明确指定该设备，防止操作到手机、模拟器或其他电视。
5. 读取真实系统 API、电视特性、CPU 架构、可用空间及现有安装状态。系统低于 API 31、非 Android 系统或必要能力不足时，停止不适用步骤。不要通过修改 APK、降低系统要求或刷机强行安装。

二、保存原桌面状态和恢复方法
1. 在首次启动或切换前，记录实际默认 HOME、全部 HOME 候选、原桌面包名与启动组件、目标用户和原始启用设置。
2. 根据实际查询结果识别原桌面，不使用其他人的包名、设备记录、禁用清单或恢复脚本。
3. 将状态和后续变更写入本机独立的操作记录，并提前保存适用于这台电视的恢复命令。保存配置不等于备份了所有应用数据。
4. 不改动与桌面替换无关的应用和服务。

三、安装并试用 Quiet TV
1. 安装随附 APK；如已有 Quiet TV，先检查版本、签名与更新条件，再执行保留数据的更新。遇到签名冲突或降级限制时停止并说明，不通过卸载、清数据或强制降级解决。
2. 核对目标用户实际安装的版本和 APK 文件哈希，再启动 home.quiet.tv/.HomeActivity。
3. 引导我验证遥控器方向键、确定键、返回键、焦点显示、应用启动和系统设置入口。
4. 新安装可能进入首次设置页面，按实际页面指导操作。预装应用管理属于独立范围，请取消与本次桌面替换无关的推荐精简项目。
5. 测试失败时先解决问题，保留原桌面可用，不继续禁用。

四、设置为默认桌面
1. 优先使用当前电视支持的系统默认桌面选择或 Quiet TV 首次设置入口；需要电视端确认时指导我完成。
2. 如需 ADB 切换，先检查当前固件支持的命令，使用实际设备、用户及 Quiet TV 的 HOME 组件。
3. 切换后查询实际默认 HOME，并让我按遥控器 Home 键确认进入 Quiet TV。命令显示 Success、应用已打开或模拟 Home 键均不能替代这项实际验证。
4. 若系统拒绝切换或仍返回原桌面，记录限制并暂停依赖该步骤的禁用操作，不先禁用原桌面来试错。

五、按实际能力禁用原桌面
1. 仅在 Quiet TV 能稳定使用、默认 HOME 已确认且恢复途径可用后，处理已核实的原桌面。
2. 检查原桌面是否与必要的设置、输入源或其他系统功能耦合。只对已确认可处理的原桌面执行针对目标用户的可恢复禁用，保留安装文件和数据。
3. 当前 APK 的系统应用管理含设备适配限制。若显示未知固件、只读或不允许操作，保留该保护，不修改规则或配置绕过；无法核实安全处理条件时保留原桌面，并说明未完成原因。
4. 每次变更后读取真实启用状态和默认 HOME，及时写入操作记录。不要批量禁用相关包，也不要扩大为系统精简。

六、验证与恢复
1. 检查 Home 键、Quiet TV 启动、常用应用和系统设置。需要我观察电视或按遥控器时，等待实际反馈。
2. 确认恢复方法可用后，再进行一次整机重启验证。待机唤醒、重开应用不能算整机重启；未实际测试的项目明确标记为待验证。
3. 出现黑屏、崩溃或关键功能失效时，优先通过仍可用的连接恢复原桌面的原始启用状态，再切回记录的原 HOME，并验证。
4. 提供可直接复制的恢复命令和操作说明，命令中的设备、用户、包名和组件必须来自本次实际记录；恢复途径也有依赖条件，需要说明。

执行边界：
- 不 root、不刷机、不恢复出厂设置、不卸载原桌面、不清除应用数据。
- 不修改投屏、语音、系统更新、影音应用等无关功能。
- 常规已授权步骤连续完成；需要我授权连接、选择目标设备或提供关键缺失信息时再询问。
- 如果缺少执行工具，如实说明，并逐步指导我执行和检查结果，不声称已经操作。
- 结束时分别报告安装、哈希、默认桌面切换、原桌面禁用、遥控器验证、整机重启验证的结果和未完成项。
```

## 分发范围

接收者只需获得 APK、校验文件和本提示词。不要附带开发者的设备配置、备份、安装回执、应用清单、日志或 ADB 私钥。该测试包在新机型上的安装成功，不代表默认桌面切换、原桌面禁用或其他系统功能已经验收。
