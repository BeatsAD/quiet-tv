# 使用 Agent 安装或恢复 Quiet TV

[首页](../README.md)  [安装与构建](INSTALL.zh-CN.md)  [兼容范围](COMPATIBILITY.md)

需要能在电脑上执行终端命令的 Agent。电脑侧 ADB 安装与 Quiet TV 内置 ADB 应用管理分别授权。没有执行工具时，Agent 应逐步指导并检查结果，不能声称已操作。

## 复制安装请求

复制下面的请求交给能执行本机命令的 AI 工具。完整操作规则见下文；Agent 须先读完整说明，无法读取时告知用户，取得说明内容后再执行设备修改。

```text
请通过我的电脑，帮我在电视上安装或更新 Quiet TV。

请先完整读取并遵循操作说明：
https://raw.githubusercontent.com/BeatsAD/quiet-tv/main/docs/AGENT_INSTALL.zh-CN.md

从官方 Releases（含预发布／测试版）选择适配电视的最新主程序。安装前告知目标版本，安装后核对实际版本和 SHA-256，不自动改装历史包。

先发现电视并让我确认目标。已有安装则保留数据更新；首次安装先试用，再让我选择是否设置默认桌面及管理应用。
需要授权或选择时等待我确认；无法读取说明、确认版本或完成操作时，停止相关修改，显示具体错误、当前状态和下一步，不猜测执行。
```

## 版本选择：包含预发布，避免误装历史包

默认安装适配目标电视的最新已发布主程序，包含预发布／测试版。当前已核对推荐为 [1.1.2 测试版](https://github.com/BeatsAD/quiet-tv/releases/tag/v1.1.2)：

| 电视系统 | APK（另下载同名 `.apk.sha256`） | 预期版本与构建号 |
| --- | --- | --- |
| 安卓 4.4 / API19–20 | [安卓 4.4 包](https://github.com/BeatsAD/quiet-tv/releases/download/v1.1.2/QuietTV_1.1.2-35_Android4.4_Test.apk) | `versionName=1.1.2`  `versionCode=35` |
| 安卓 5 及以上 / API21+ | [标准包](https://github.com/BeatsAD/quiet-tv/releases/download/v1.1.2/QuietTV_1.1.2-34_Android5plus_Test.apk) | `versionName=1.1.2`  `versionCode=34` |

- 读取[完整发布列表](https://github.com/BeatsAD/quiet-tv/releases)；使用 API 时读取 `https://api.github.com/repos/BeatsAD/quiet-tv/releases`，有下一页则继续读取。排除草稿，保留 `prerelease=true`，结合软件版本、实际附件及兼容信息选包。不能仅依赖 `/releases/latest` 或 `/releases/latest/download/...`：它们不包含预发布；当前仓库均为预发布，前者返回 404 不代表没有新版本。
- 若有更新的适配版本，以实时发布列表为准；按系统、架构和已有安装选包，不跨档比较最大构建号。1.1.0、b26、b30 等历史包不作为当前默认下载，搜索摘要、本机缓存和已有 APK 不作为“最新”的依据。用户明确指定历史版本时，另行说明版本差异与升级限制。
- 安装前在对话中列明选中的 Release、下载地址、目标 `versionName` 和 `versionCode`，核对实际 APK 与同名校验文件。读取发布信息或下载失败时停止安装并报告原因，不自动退回历史包，不从源码构建替代已发布包。
- 安装后拉取实际已安装 APK，核对包名、`versionName`、`versionCode` 和 SHA-256 均与选定目标一致。目标为 1.1.2 而实际仍为 1.1.0 时必须报告“版本验证失败”，不能只因 `adb install` 返回 `Success` 就声称已更新。

## Agent 操作顺序

1. **确认目标**：检查电脑工具、现有 ADB 连接和 mDNS，必要时仅在电脑当前局域网扫描常用 ADB 连接端口，不跨网段或做全端口扫描。无论发现一台还是多台，都让用户确认目标；未发现时再指导用户提供实际地址和端口或 USB 设备标识。后续 ADB 命令始终指定同一设备。根据电视实际入口选择 USB、传统网络 ADB 或无线配对；配对端口与连接端口分别核对，授权由用户现场确认，不把投屏码当作配对码。无授权通道时停止依赖 ADB 的步骤；如果电视允许手动安装，继续提供普通 App 试用路径。
2. **只读检测**：读取品牌、完整型号、Android/API、CPU 架构、固件指纹、当前用户、Quiet TV 安装及启用状态、版本和签名，以及 HOME 候选和实际解析结果。先读取 `pm help` 和可用的 `cmd package help`，不预设用户 0、端口 5555 或现代子命令存在。分别判断 ADB 连接与授权、应用扫描、安装、HOME 切换、禁用及恢复能力；型号和 Android 版本不能代替实际能力检查。没有可靠查询结果时标明“未确认”，不能当作未安装。
3. **识别安装场景**：按下方“已有安装”或“首次安装”分流。当前用户已禁用、仅其他用户安装或当前用户已卸载但系统仍保留包的情况单独说明，询问是否恢复使用，不自动启用、恢复安装或当作首次安装。实验专用包名与普通包不混为覆盖升级。
4. **保存恢复基线**：在安装前保存可读取的旧版本、签名、实际 APK、当前 HOME 和应用启禁状态；首次启动或切换前补齐原主页组件、原始启用状态、目标用户及本机可用恢复路径。更新时保留原有恢复记录，不用当前 Quiet TV HOME 覆盖原桌面记录。保存在电脑私有目录；不上传设备标识、地址、密钥、完整转储或应用清单。系统选择器不能当成原桌面，记录不等于应用数据备份；无法读取的私有设置不能声称已备份。
5. **选择与校验安装包**：按上方“版本选择”规则读取含预发布的发布列表和[兼容说明](COMPATIBILITY.md)，选择最新适配主程序。若安装或兼容文档仍引用旧下载，下载信息以对应 Release 正文及实际附件为准，并核对 APK 的真实包名、版本、最低 API、原生库架构、签名与 SHA-256。普通包为 `home.quiet.tv`，实验专用包和助手不自动替代。下载实际 APK 与相同下载文件名的 `.apk.sha256`；原中文文件名校验记录不用于直接校验英文名下载。签名冲突、降级或缺少匹配包时停止安装并说明原因，不卸载、清数据、强制降级或擅自改包。
6. **安装并核对**：保留数据安装，读取目标用户的实际安装路径，拉取已安装 APK 核对版本、包名与 SHA-256。多 APK 安装逐项核对，单个 base.apk 不能证明整个集合。核对失败或无法读取时报告具体原因，不能仅凭安装命令的 `Success` 宣称校验通过。
7. **分项交付**：按所选分支验证结果，提供根据本次记录生成的恢复步骤。重启、断电冷启动、待机唤醒分别验证；重启和设备电源操作需有明确授权和可用恢复路径。失败或连接丢失时按下方要求报告，只查询现状，不自动重放安装、切换或禁用。

## 已有安装：只更新

| 检测结果 | 处理 |
| --- | --- |
| 适用档位有更高 `versionCode`，包名及签名匹配 | 保留数据覆盖升级，保持原默认桌面、应用启禁状态及设置，不重新执行首次设置或精简。 |
| 已安装版本与适用发布文件的版本及 SHA-256 相同 | 告知无需重装；如用户有故障，另行诊断，不用重装代替判断。 |
| `versionCode` 相同但文件不同，或已安装构建号更高 | 说明差异并停止覆盖，不默认修复、换档或降级。 |
| 包名、签名、系统或架构不匹配 | 明确不满足的条件，停止直接覆盖，不通过卸载解决。 |

覆盖后核对版本与已安装文件，再检查原 HOME 和启禁状态是否保持，请用户确认桌面能打开、壁纸与排序等原设置仍在。更新通常不会强制首次设置；如出现引导或状态变化，报告差异，不自动重新配置。用户另行要求调整默认桌面或应用时，再进入对应可选流程。

## 首次安装：试用、默认桌面与可选管理

1. **先安装试用**：首次设置选择“暂不设置，临时使用”，验证方向、确定、返回、应用启动、设置和信号源。ADB 不可用时，如果电视允许手动安装 APK，继续提供手动试用路径；不声称已经自动安装或能解锁调试。
2. **选择默认桌面**：试用可用后询问用户是否设为默认。用户选择继续时，优先系统选择或“全部应用 → 应用管理 → 更多 → 首次设置”；ADB 切换命令须在实际固件帮助中存在并支持目标用户。重新查询 HOME，再请用户按实体 HOME 并等待反馈。用户只试用、拒绝授权、固件拒绝或结果未确认时，保留原桌面，停止依赖切换成功的后续管理。
3. **可选禁用原桌面**：默认保留。仅在 Quiet TV HOME 组件可用、系统 HOME 已核对指向 Quiet TV、实体 HOME 已由用户确认、本机原桌面身份及原状态明确、适配规则允许禁用且具备恢复命令与路径时，才向用户提供禁用选项；用户明确选择后执行。禁用后重新设置并核对 HOME，再验证实体按键。不通过禁用原桌面试错，不卸载原桌面。重启、冷启动和唤醒仍需单独验收。
4. **选择应用**：扫描当前电视实际应用，列出名称、包名、用途、当前状态、拟执行操作、影响及恢复办法，区分“可禁用”和“只读／待确认”。按发布包对应的[固件规则](../app/src/main/assets/setup-presets.json)核对指纹、品牌及规则要求的机型和操作资格；上游参考不授予资格，未知系统包和关键组件保持只读。可引导用户在现有首次设置界面选择；界面可能已有预选项，执行前仍须逐项核实并让用户确认，预选不等于授权。用户可选择“不处理，进入桌面”。
5. **逐项执行**：电脑 ADB 和 Quiet TV 内置 ADB 分别授权。选择完成后重新核对目标、用户、HOME 和整组包状态，只禁用本次明确选择且资格未变化的项目，保留安装和数据。每项执行一次并读回、记录原状态与结果；失败停止后续修改，不把多项成功操作当作可自动回滚事务。恢复仅处理本次实际发生且有记录的变更。

外部 Agent 直接执行 shell 不会自动受到应用内检查约束，也必须遵循上述资格与顺序；不能绕过只读限制。应用能安装、能设置 HOME、能禁用原桌面、能管理其他系统应用是独立能力。新源码或实验助手不等于已发布 APK 的功能，不自动部署未发布的主页守护或助手。

## 失败时直接在 AI 对话显示

下载、连接、授权、安装、HOME、应用管理、恢复和验证中的失败，均立即显示在当前 AI 编程工具的对话中；不能只显示“失败”、只记录在文件、只让用户去电视找日志，或等待最后统一报告。

```text
失败步骤：<正在执行的操作与目标>
相关命令：<必要命令，设备地址、序列号等脱敏；界面操作则写操作路径>
退出状态：<本机退出码及可取得的远端退出状态；未取得写“未知”>
原始错误：<相关标准输出、标准错误或工具异常；无输出也明确说明>
原因判断：<已经确认的原因；可能原因和待确认项分别写明>
当前状态：<已完成、已修改、未执行、已核对或结果未确认>
下一步：<可继续的独立检查、用户需做的操作及本机恢复办法>
```

- 保留必要的原始错误码和错误文本，不隐藏错误输出或只给通用结论。原始内容只摘录相关脱敏片段，不输出配对码、令牌、密钥或完整设备转储。工具缺失、无权限、无法访问文档或无法取得日志也直接说明。
- 命令返回成功但版本、哈希、HOME 或包状态不符时，明确报告“验证失败”及预期、实际差异。超时、断连或缺少可靠输出时报告“结果未确认”，不推断成功或完全没有修改。
- 停止失败步骤及依赖它的后续修改，继续已授权且不依赖该结果的只读检查。重新读取实际状态后再决定后续；不自动重复修改、卸载重装、清数据或扩大到无关系统包。
- 原因无法确认就说明缺失证据；连接超时不等于固件封锁，HOME 查询正确不等于实体按键成功。用户的电视画面和实体反馈须单独记录。

## 结果要求

| 项目 | 应报告的证据 |
| --- | --- |
| APK | 选定 Release、来源、目标与实际版本及构建号、系统档位、签名、下载与已安装文件校验 |
| 安装 | 指定设备和用户上的实际安装结果 |
| 系统 HOME | 真实查询结果；不支持查询则为未知 |
| 实体 HOME | 用户实际按键后的画面；ADB 注入只算单独证据 |
| 重启、冷启动、待机唤醒 | 各自完成、失败或未执行，不能互相替代 |
| 原桌面与恢复 | 是否保留、本机恢复步骤、依赖条件和私有记录位置 |
| 可选应用管理 | 用户确认的选择、规则依据、每项原状态、执行与读回结果；未选择则未执行 |
| 失败 | 失败步骤、脱敏命令、退出状态与原始错误、原因判断、当前状态和下一步 |

`Success`、应用已打开、HOME 已解析、服务已绑定及实际按键行为是不同证据。只贴必要命令的脱敏输出，不公开完整日志。无障碍或通知监听写入配置不代表已绑定、收到事件或能接管 HOME。

本流程不 root、不刷机、不恢复出厂、不清数据、不卸载原桌面；禁用仅限用户明确选择且满足上述规则的项目，不操作无关系统包，也不默认保持 ADB 常开。安装和源码同步不授权发布 APK。

安装、HOME 或运行异常需要取证时，使用[Agent 问题排查](AGENT_DIAGNOSE.zh-CN.md)，排查不自动重复安装或修改系统。

## 请求恢复原桌面

恢复前读取现状和本机私有记录，核对目标设备、用户、原桌面组件及原始启用状态。优先使用系统选择、Quiet TV 恢复入口或已验证的本机路径，只恢复实际发生且有记录的变更；原桌面未禁用就不执行启用。保留 Quiet TV 和其他应用数据，记录或权限不足时说明缺失项，不猜原值、不套用其他电视的命令。完成后读回 HOME，等待用户验证实体按键；重启、冷启动和待机结果分别报告，电源操作先确认。失败处理遵循上文要求，不自动重放修改。

```text
请通过我的电脑，帮我恢复电视原来的桌面。
```
