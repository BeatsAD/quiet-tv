# 使用 Agent 安装或恢复 Quiet TV

[首页](../README.md)  [安装与构建](INSTALL.zh-CN.md)  [兼容范围](COMPATIBILITY.md)

需要能在电脑上执行终端命令的 Agent。电脑侧 ADB 安装与 Quiet TV 内置 ADB 应用管理分别授权。没有执行工具时，Agent 应逐步指导并检查结果，不能声称已操作。

## 复制安装请求

复制下面的请求交给能执行本机命令的 AI 工具。完整操作规则见下文；Agent 须先读完整说明，无法读取时告知用户，取得说明内容后再执行设备修改。

```text
请通过我的电脑，帮我在电视上安装或更新 Quiet TV。

请先完整读取并遵循操作说明：
https://raw.githubusercontent.com/BeatsAD/quiet-tv/main/docs/AGENT_INSTALL.zh-CN.md

从官方 Releases（含预发布／测试版）选择适配电视的最新主程序。安装前告知目标版本，安装后核对实际版本和 SHA-256，不自动改装历史包。

先发现电视并让我确认目标。已有安装则保留数据更新；首次安装先试用，再让我选择是否设置默认桌面及管理应用。
需要授权或选择时等待我确认；无法读取说明、确认版本或完成操作时，停止相关修改，显示具体错误、当前状态和下一步，不猜测执行。
```

## 版本选择：包含预发布，避免误装历史包

默认安装适配目标电视的最新已发布主程序，包含预发布／测试版。当前已核对推荐为 [1.1.2 测试版](https://github.com/BeatsAD/quiet-tv/releases/tag/v1.1.2)：

| 电视系统 | APK（另下载同名 `.apk.sha256`） | 预期版本与构建号 |
| --- | --- | --- |
| 安卓 4.4 / API19–20 | [安卓 4.4 包](https://github.com/BeatsAD/quiet-tv/releases/download/v1.1.2/QuietTV_1.1.2-35_Android4.4_Test.apk) | `versionName=1.1.2`  `versionCode=35` |
| 安卓 5 及以上 / API21+ | [标准包](https://github.com/BeatsAD/quiet-tv/releases/download/v1.1.2/QuietTV_1.1.2-34_Android5plus_Test.apk) | `versionName=1.1.2`  `versionCode=34` |

- 读取[完整发布列表](https://github.com/BeatsAD/quiet-tv/releases)；使用 API 时读取 `https://api.github.com/repos/BeatsAD/quiet-tv/releases`，有下一页则继续读取。排除草稿，保留 `prerelease=true`，结合软件版本、实际附件及兼容信息选包。不能仅依赖 `/releases/latest` 或 `/releases/latest/download/...`：它们不包含预发布；当前仓库均为预发布，前者返回 404 不代表没有新版本。
- 若有更新的适配版本，以实时发布列表为准；按系统、架构和已有安装选包，不跨档比较最大构建号。1.1.0、b26、b30 等历史包不作为当前默认下载，搜索摘要、本机缓存和已有 APK 不作为“最新”的依据。用户明确指定历史版本时，另行说明版本差异与升级限制。
- 安装前在对话中列明选中的 Release、下载地址、目标 `versionName` 和 `versionCode`，核对实际 APK 与同名校验文件。读取发布信息或下载失败时停止安装并报告原因，不自动退回历史包，不从源码构建替代已发布包。
- 安装后拉取实际已安装 APK，核对包名、`versionName`、`versionCode` 和 SHA-256 均与选定目标一致。目标为 1.1.2 而实际仍为 1.1.0 时必须报告“版本验证失败”，不能只因 `adb install` 返回 `Success` 就声称已更新。

## Agent 操作顺序

1. **确认目标**：检查电脑工具和现有连接，让用户确认目标电视；不能因为只有一台在线就自动选择。后续 ADB 命令始终指定相同设备。根据电视实际入口选择 USB、传统网络 ADB 或无线配对。无授权通道时停止依赖 ADB 的步骤；如果电视允许手动安装，继续提供普通 App 试用路径。
2. **只读检测**：读取 Android/API、CPU 架构、当前用户、已安装 Quiet TV、HOME 候选及解析结果。旧系统先读取 `pm help` 和可用的 `cmd package help`，不预设用户 0、端口 5555 或现代子命令存在。
3. **保存恢复基线**：首次启动或切换前记录原主页组件、原始启用状态、目标用户及本机可用恢复路径。保存在电脑私有目录；不上传设备标识、地址、密钥、完整转储或应用清单。系统选择器不能当成原桌面。基线记录不等于应用数据备份。
4. **选择安装包**：按上方“版本选择”规则读取含预发布的发布列表和[兼容说明](COMPATIBILITY.md)，选择最新适配主程序。读取实际 APK 的包名、版本、最低 API、原生库架构及签名，核对发布的 SHA-256。普通包应为 `home.quiet.tv`，实验专用包不自动替代。已安装时核对相同包名、签名及递增构建号；签名冲突、降级或缺少匹配包时说明原因，不卸载、清数据、强制降级或擅自改 APK。
5. **安装并试用**：保留数据安装，读取实际安装路径，拉取已安装 APK 核对版本与 SHA-256。新安装在首次设置选择“暂不设置，临时使用”，跳过无关预装应用管理；验证方向、确定、返回、应用启动、设置与信号源。多 APK 安装需要逐项核对，单个 base.apk 不能证明整个集合。
6. **按目标切换**：仅“安装试用”到此结束。“尝试设为默认桌面”优先用系统选择或首次设置；ADB 命令必须在当前固件帮助中存在并支持目标用户。执行后重新查询 HOME，再请用户按实体 HOME。失败时保留原桌面，记录限制；不能禁用原桌面试错，也不能将实验助手视作主程序已有功能。
7. **验收与恢复**：提供根据本次记录生成的恢复步骤，优先使用系统选择或已验证的切换命令切回原组件。原桌面未被禁用就不执行启用命令。重启、断电冷启动、待机唤醒分别验证；重启和设备电源操作需有明确授权和可用恢复路径。连接丢失时只查询现状，不自动重放安装或切换。

## 结果要求

| 项目 | 应报告的证据 |
| --- | --- |
| APK | 选定 Release、来源、目标与实际版本及构建号、系统档位、签名、下载与已安装文件校验 |
| 安装 | 指定设备和用户上的实际安装结果 |
| 系统 HOME | 真实查询结果；不支持查询则为未知 |
| 实体 HOME | 用户实际按键后的画面；ADB 注入只算单独证据 |
| 重启、冷启动、待机唤醒 | 各自完成、失败或未执行，不能互相替代 |
| 原桌面与恢复 | 是否保留、本机恢复步骤、依赖条件和私有记录位置 |

`Success`、应用已打开、HOME 已解析、服务已绑定及实际按键行为是不同证据。只贴必要命令的脱敏输出，不公开完整日志。无障碍或通知监听写入配置不代表已绑定、收到事件或能接管 HOME。

本流程不 root、不刷机、不恢复出厂、不清数据、不卸载或禁用原桌面，不操作无关系统包，也不默认保持 ADB 常开。安装和源码同步不授权发布 APK。

安装、HOME 或运行异常需要取证时，使用[Agent 问题排查](AGENT_DIAGNOSE.zh-CN.md)，排查不自动重复安装或修改系统。

## 请求恢复原桌面

```text
请通过我的电脑，帮我恢复电视原来的桌面。

请先完整读取并遵循操作说明：
https://raw.githubusercontent.com/BeatsAD/quiet-tv/main/docs/AGENT_INSTALL.zh-CN.md

确认目标电视后，根据本机记录恢复，保留 Quiet TV 和应用数据。
失败时显示具体错误、当前状态和下一步；记录缺失或无法读取说明时先告诉我，不猜测执行。
```

## 开发版兼容守护

仅当用户授权配置桌面接管且实际安装包包含相应组件时，才配置兼容守护的无障碍、通知访问及写安全设置能力；使用实际包名和已核对用户。首次权限配置不等于开机验收。新开发版进入配置后默认为自动，后续重启无需重复确认；系统 HOME 仍属原桌面时不得报告默认 HOME 已修改，不因守护可运行而禁用原桌面。用户明确暂停后不得重启、重绑或更新替其打开。历史安装包不因本文更新而获得该能力。
