# ADB开启：按型号与固件匹配

[统一入口](../AGENT.md)  [连接与工具准备](connect.md)。只在尚未开启ADB、菜单不符或需要核对厂商连接差异时读取。已有授权连接直接复用；unauthorized、offline、端口错误转连接诊断，不重复解锁菜单。

## 先确定设备，再选择入口

1. **先取得必要信息**：先确认品牌、实际系统和当前设置页面，复用用户已提供的型号、地区及版本。遇到型号／固件限定的方法或页面不符时，再从铭牌、关于页补齐对应条件；不把完整固件号作为所有品牌指引的前置要求。保留原文，未知留空，不要求先执行ADB找入口，也不把“Smart TV Pro”“VIDAA_TV”等通用系统名当作精确型号。
2. **按品牌定位，优先具体记录**：只读下表对应品牌段。已知型号／固件有专门记录时优先核对，不能用品牌通用方法覆盖已知不适用或受阻情况。使用限定型号／固件的记录时，按其型号、平台、地区、系统及完整构建号匹配；相近型号、同SoC、版本前缀不代替匹配，缺项记“条件待确认”。
3. **有准确品牌指引就直接指导**：官方或可靠项目文档明确给出该品牌／系统的完整开启流程，当前页面与步骤吻合，且没有已知本机反例时，按其适用范围直接给用户下一步操作。无需先取得文档未要求的完整固件号，也不因“Quiet TV未验证”就拒绝提供有依据的步骤。品牌指引只表示这条路径可指导，不保证全品牌兼容或已经连通。仅见于个别型号报告的暗码、工厂参数、USB接线或辅助APK仍按该记录限定，不能升级为品牌通用方法。
4. **按验证状态处理**：资料中的“完整入口”指上游写到开关，不表示本机授权成功。入口不完整、连接受阻、待验证线索只用于排查，不能拼接邻近型号步骤补成教程，也不依次试遍同品牌暗码。默认开启的记录仍须核对本机当前连接与授权。
5. **逐步指导并确认结果**：先给出当前可执行的步骤，简短附上出处及适用条件，不让用户先读整张资料表。按实际页面继续，页面不符就停在该步补证据；资料编号、匹配依据和未验证项写入任务记录。工厂入口只处理明确调试项；涉及To Fac等参数时另核对该型号固件、原值、影响和恢复办法，再按实际授权处理，不把开启ADB的选择扩展到任意工厂修改。
6. **连接后补齐身份**：取得授权会话后读取实际型号、API及固件指纹，与连接前材料复核；不一致则撤销原匹配结论。后续安装、HOME、ADB保持分别沿用既有分支，不能用开启报告增加接管或应用禁用资格。

现场工具 `device_environment.py adb` 的 `guide` 是按系统给出的标准参考，`research` 是待检索状态；它们都不自动匹配本资料表。Agent负责上述核对，不从品牌名称生成执行资格。缺少匹配项时继续电脑工具准备，记录缺项并定向查官方说明和原始设备报告，不宣称该品牌永远无法开启。

## 连接与验收

- **普通网络ADB**：只有本机已开放相应端口才连接；5555只是常见值，Wanbo资料有5877，不能默认所有电视都用5555。第一次授权与端口开放分开核对。
- **无线调试配对**：以电视实际显示的配对页和连接页为准，`adb pair <IP>:<配对端口>`与`adb connect <IP>:<连接端口>`使用各自端口。可用 `adb mdns services`核对服务，连接服务不等于配对服务。仅随机TLS连接端口但没有配对入口时报告受阻，不猜码或降级绕过授权。
- **USB再转TCP**：仅限该型号／固件及物理接口确实支持USB设备端调试且用户已现场授权。不能把任意两个USB-A主机口直接连接。先有可用授权会话，才可按授权执行 `adb -s <已授权USB序列号> tcpip <已核对端口>`；这条命令不能在完全未连接时远程开启ADB。
- **辅助APK**：只在指定型号固件有依据且存在独立合法安装通道时作为候选；工具可能仅唤起已有设置或依赖厂商权限。不能先要求ADB安装开启器，也不能因别的投影型号成功就宣称本机支持。未经核对不自动下载、安装或运行第三方开启器。
- **成功标准**：分别记录开关状态、端口／传输、`adb devices -l`中目标为`device`、指定目标的只读shell结果。授权框由用户确认；部分旧固件报告无授权框，也须按本机证据记录。ADB连通不等于APK能安装、HOME能切换或权限为root。
- **保持与电源场景**：配对记录保留不等于端口保留，开关保持不等于重启能重连。沿用[ADB保持](home.md)和[验收](acceptance.md)，重启、冷启动、待机唤醒按实际授权分别验证。上游“用后关闭”的偏好不覆盖用户已选择的Quiet TV ADB保持；无认证网络调试应说明实际暴露范围，按用户选择处理。

Android官方无线配对说明区分手机Android 11+与TV／Wear OS Android 13+；厂商固件可能定制，不能只按系统大版本推定配对或固定5555。参考[Android ADB](https://developer.android.com/tools/adb)、[Fire TV ADB](https://developer.amazon.com/docs/fire-tv/connecting-adb-to-device.html)及资料中的指定固件记录。
