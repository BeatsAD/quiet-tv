# 应用管理原生界面改版

2026-10-18，按用户确认的应用管理交互原型实现；独立网页演示工程已停止跟踪，原生实现的设计记录保留如下。继续使用 Java、原生 View 和 RecyclerView，不引入网页容器或新运行时依赖。

## 实现

- 应用列表／常用应用使用同一标题栏、48 逻辑像素外边距、暗色玻璃材质及白色焦点描边。背景读取当前壁纸设置并加深遮罩，不修改壁纸偏好。
- ADB 状态收为右上角紧凑入口；端口、当前用户、本机地址及开发者设置放在连接弹窗。连接、等待授权、失败状态仍来自真实控制器。
- 搜索、筛选保留在工具栏；刷新和操作记录移入“更多”。搜索结果显示可清除的查询标签，空结果有明确提示。
- 左栏约四成宽，显示应用实际图标、名称、类型、状态及常用应用标记；包名、版本集中到右栏。无自带图标的包使用统一四宫格图标。
- 右栏图标、名称、状态和元信息居中；启停与卸载采用横排紧凑按钮。预装卸载仍明确限定当前用户；保护组件只读。
- 弹窗统一材质及尺寸，确认默认聚焦“取消”。操作成功使用短暂页内提示；失败保留可读弹窗，不自动重复命令。
- 常用应用展示四个实际横幅卡片；无横幅时显示应用图标，空位显示添加入口。禁用后保留位置，添加、替换、移除、左右排序沿用原有配置语义。
- 首页“应用管理”改为中性灰渐变和四宫格图标；图标、间距和文字按整体高度居中。空 Dock 的添加入口使用加号，顶部原有设置图标保持不变。
- 遥控器右键从列表进入详情；详情中可在两个按钮之间左右移动，首按钮左键或详情返回键回到原列表项。排序确定保存、返回取消。

不把原型中的预览标题、演示数据重置、背景切换器加入产品。包操作、当前用户验证、固件保护清单及日志机制保留原实现。
