# 应用管理与常用应用

[首页](../README.md) · [使用指南](USAGE.zh-CN.md) · [首次设置与恢复](SETUP.md)

## 入口与列表

全部应用 → 应用管理。列表显示名称、包名、版本、预装／用户类型和当前状态，支持名称／包名搜索及全部、用户、预装、禁用、可恢复筛选。未连接 ADB 时仍可读取本地包信息。

## 常用应用 / Dock

首页最多保留四个常用应用。支持添加、移除、满位替换和左右排序；排序按确定保存、返回取消。禁用保留配置，明确卸载后移除对应配置，应用更新不作为卸载处理。配置保存在电视本地。

## 本机连接与单应用操作

系统包操作按需连接电视本机 ADB，在设备上确认授权；密钥由应用私有目录保存。传统 TCP 可按实际端口连接；无线配对仍是待验收实验入口，见[兼容范围](COMPATIBILITY.md)。

启用、禁用、当前用户卸载与符合条件的恢复安装逐个包执行：重新读取状态、核对用户选择、写入运行记录、执行一次并读回结果。执行前检查本机身份、当前用户、包状态、保护规则和系统命令能力；超时、断连或结果不明时不自动重试修改命令。

关键系统组件和可识别的 HOME 包保持保护；原桌面通过首次设置／恢复专用流程处理。未知固件不会继承其他设备的系统包操作权限。

## 数据与恢复

禁用保留安装和数据；卸载删除当前用户数据。恢复安装只恢复符合条件的预装包，不恢复已删除数据。应用私有记录不是完整备份；操作前保存自己的设备基线。

“更多”提供刷新、首次设置、恢复原桌面及操作记录。预装应用卸载／恢复、其他固件和长期运行仍需分别真机验收，不能用历史普通测试包的结果替代。详细阶段记录和证据仅保留本地。
