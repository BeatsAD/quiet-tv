# 使用指南

## 遥控器

| 操作 | 行为 |
| --- | --- |
| 左／右 | 在当前行移动，到行末停止 |
| 上／下 | 在快捷按钮、Dock 与应用网格之间逐行移动 |
| 确定 | 打开选中的应用、系统入口或壁纸设置 |
| 网格中按返回 | 返回 Dock |
| 应用中按 HOME | 回到 Quiet TV，恢复上次焦点 |

全部应用与首页排序均按每行五项显示。最后一行不足五项时，焦点落到最近的有效列。焦点会保存到本地，桌面进程重启后恢复；本次索尼机型已完成一次整机重启，确认自动进入桌面及 Dock／壁纸配置保留；长时间运行仍待验收。

## 应用管理与 Dock

在首页下方“全部应用”选择“应用管理”。顶部仍保留信号源、网络和系统设置。

- **Dock 管理**：最多 5 个。选位置后可替换、移除，或进入左右排序；确定保存，返回取消。空位从已安装、已启用且有启动入口的应用中添加。移除只改变快捷入口。
- **首页排序**：在“应用管理 → 首页排序”调整首页下方应用，包括壁纸设置和应用管理入口。确定拿起，方向键移动，再次确定放下；返回取消本次移动，点击“保存顺序”才会生效。离开未保存页面时可保存、放弃或继续编辑。“恢复默认”也需保存后生效。
- **应用列表**：左侧列表、右侧详情；可按应用名或包名搜索，并筛选全部、用户、预装、已禁用或可恢复的应用。
- **ADB 设置**：点击右上状态按钮，开启电视网络调试后填写端口（传统 TCP 默认 5555），在电视弹窗允许 QuietTV。首版仅适配当前索尼固件的本机 TCP；配对码式无线调试尚未支持。
- **系统操作**：只针对当前 Android 用户下的单个应用。禁用保留数据；卸载会删除该用户的应用数据。预装应用的“为当前用户卸载”不删除系统分区 APK；仅保留安装包的系统应用可恢复安装，不恢复已删除数据。
- **只读保护**：Quiet TV、自身验证组件、关键系统组件及未经当前机型确认的预装包不提供修改按钮。
- **操作记录**：保存操作前后状态和结果，是配置记录，不是应用数据备份。连接中断时先重新连接并刷新，不重复点击卸载。

Dock 编辑不依赖 ADB。禁用的 Dock 应用暂时隐藏并保留顺序，启用后恢复；核对卸载成功后移除其快捷配置。设置在电视本地保存，APK 更新不会覆盖用户的 Dock，包括主动清空的配置。

首页排序同样不依赖 ADB，顶部 Dock 保持独立。保存自定义顺序后，新出现的应用追加到末尾；应用改名或更新保持位置。禁用或加入 Dock 时保留原位置记录，恢复显示后按记录排列；卸载后清除记录。恢复默认后，壁纸设置和应用管理在前，其余按名称排列。配置保留在本机，正常覆盖更新不清除；真实电视的遥控、重启与更新保留情况需在对应设备上验收。

实机证据与支持边界见[管理功能验收](APP_MANAGEMENT.md)。

## 语言与初始配置

修改 `app/src/main/assets/launcher.json` 后重新构建并更新安装：

```json
{
  "language": "zh",
  "greeting": "time",
  "dock": ["com.trim.tv", "com.xiaodianshi.tv.yst", "top.yogiczy.slcs.tv", "com.xunlei.downloadprovider.hd"],
  "hidden": ["com.dangbei.TVHomeLauncher", "com.android.tv.settings", "com.sony.dtv.settings"]
}
```

这是当前索尼机型的配置示例，包名需按自己的已安装应用调整。`dock` 为首次迁移使用的最多五个应用包名，顺序从左到右；首次迁移后请使用界面管理，修改资源不会覆盖已保存的 Dock。`hidden` 只影响桌面显示，不禁用包。`language` 使用 `zh` 或 `en`；`greeting` 使用 `time` 或 `home`。当前代码不支持提示词中规划的 `system` 自动语言模式。

## 壁纸

在“全部应用”中进入“壁纸设置”。左右移动预览，确定或点击“使用这张壁纸”保存选择；普通模式按返回取消未应用的预览并回到桌面。管理模式按返回先退出管理，已完成的删除不会撤销。

- **默认颜色主题**：纯黑背景加主题色光晕，随选中应用换色，始终保留且不可删除。
- **图片与轮播**：确认一张图片会关闭轮播；开启轮播后，保留的内置图和用户图片每 5 分钟切换一次。打开选择页或离开桌面时暂停，回来后重新计时。
- **管理**：点击右上角“管理”后可单张删除。内置图片从列表和轮播中移除，可通过“恢复内置壁纸”找回；用户图片删除电视中保存的副本。删除当前固定图片后回到默认颜色主题，轮播当前图片被删除时切到下一张；不足两张图片时自动关闭轮播。
- **上传**：点击右上角“上传壁纸”，用同一局域网中的手机或电脑扫描二维码，或打开电视显示的完整会话地址。选择图片上传，成功后在电视按返回，再选择该图片应用。无需 ADB、账号或云端服务，电视也可通过网线连接。

支持 JPG、PNG、静态 WebP；单张最多 20 MB、4000 万像素，最多 20 张用户图片，处理后总容量最多 50 MB。保存的显示图最长边不超过 1920 像素，自动校正方向，按等比铺满、居中裁切显示；透明区域以黑色背景呈现。电视只保留处理后的图片，不影响手机或电脑原图。HEIC 照片请先转换为 JPG。

上传服务仅在电视上传弹窗打开期间运行，关闭、进入后台、网络地址变化或空闲 10 分钟后结束；旧地址随会话失效。连接失败时请检查访客网络／设备隔离，并尝试在系统浏览器中打开完整地址。上传失败或空间不足不会替换已有壁纸。

覆盖更新保留壁纸与移除状态；卸载或清除 Quiet TV 数据会移除用户图片。旧版本的壁纸选择和轮播模式在首次启动时迁移。上述新增管理与上传对应当前源码，现有 b26 下载包不包含本次功能，电视实机验收仍待完成。图片来源与使用边界见[第三方资源说明](../THIRD_PARTY_NOTICES.md)。

## 信号源、网络与设置

信号源菜单来自电视真实 TV Input 列表。当前索尼机型列出 HDMI 1–4、AV 和电视直播；其他设备以实际输入为准。频道为空时提供设置入口，不自动搜台。网络按钮打开网络设置，另一个设置按钮打开系统设置。

新增源码会在标准输入服务缺失、受限或返回空列表时，检查已知的原厂信号源面板。只有实际存在、已启用且允许 Quiet TV 调用的系统组件才会作为入口；只有一个可用面板时直接打开，多个面板时显示选项。有正常输入列表时保留该列表，并提供可用的系统信号源入口。BYINTEK U4 上游报告的虚假标准列表采用原厂面板优先策略。标准切换调用报错时，可选择系统信号源面板；画面黑屏但调用未报错时，可返回菜单手动选择系统入口。

没有可用入口时显示具体原因并提供系统设置，不能据此判断电视没有 HDMI／AV。面板被禁用或权限受限时不会自动启用组件或修改权限。海信、TCL、BYINTEK 的候选入口与验收边界见[信号源兼容](COMPATIBILITY.md#信号源兼容)。公开 b26 不包含此回退功能；源码构建成功不代表目标电视已经可以切换。

有线网络已验证。Wi-Fi 名称依赖位置权限与定位开关，当前未完成实机切换验收。应用能打开不代表账号、播放、声音或第三方服务已经验收。

## 更新与恢复

按[安装指南](INSTALL.zh-CN.md)重新构建和更新 Quiet TV。第三方应用通过各自渠道更新。系统精简的恢复依赖目标设备自己的原始备份和 journal；不要在其他电视运行仓库已有的索尼恢复清单。
