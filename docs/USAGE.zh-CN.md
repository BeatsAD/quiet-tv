## 遥控器

| 操作 | 行为 |
| --- | --- |
| 左／右 | 在当前行移动，到行末停止 |
| 上／下 | 在快捷按钮、Dock 与应用网格之间逐行移动 |
| 确定 | 打开选中的应用、系统入口或设置模块 |
| 网格中按返回 | 返回 Dock |
| 应用中按 HOME | 回到 Quiet TV，恢复上次焦点 |

全部应用与首页排序均按每行五项显示。最后一行不足五项时，焦点落到最近的有效列。焦点会保存到本地，桌面进程重启后恢复；历史版本曾在一台索尼电视完成一次整机重启；该记录不作为 1.1.2 的重启或升级保留验收。

开发版进入“全部应用”后收紧顶部间距，时间日期与可见快捷按钮保持固定，更多应用随焦点按行连续滚动，不显示滚动条、应用数量或底部辅助文字。从第一行按上或在网格中按返回，恢复首页原有布局及离开前的 Dock 焦点。此调整尚未包含在已发布的 1.1.2 安装包中。

本指南对应已发布的 [1.1.2 测试版](https://github.com/BeatsAD/quiet-tv/releases/tag/v1.1.2)。截图取自索尼电视的标准档 34，不能代替各功能与其他电视验收。

## 应用管理与 Dock

在首页下方“全部应用”选择“应用管理”。顶部默认显示信号源、网络和系统设置，可在“桌面设置”中分别隐藏。

- **Dock 管理**：最多 5 个。选位置后可替换、移除，或进入左右排序；确定保存，返回取消。空位从已安装、已启用且有启动入口的应用中添加。移除只改变快捷入口。
- **首页排序**：在“应用管理 → 首页排序”调整首页下方应用，包括壁纸设置、桌面设置和应用管理入口。确定拿起，方向键移动，再次确定放下；返回取消本次移动，点击“保存顺序”才会生效。离开未保存页面时可保存、放弃或继续编辑。“恢复默认”也需保存后生效。
- **应用列表**：左侧列表、右侧详情；可筛选全部、用户、预装、已禁用或可恢复的应用。
- **ADB 设置**：点击右上状态按钮，开启电视网络调试后填写端口（传统 TCP 默认 5555），在电视弹窗允许 QuietTV。传统 TCP 需固件实际提供服务；六位码无线配对为 API33+ 且依赖设备能力的实验入口，安卓4.4兼容档不提供。
- **系统操作**：只针对当前 Android 用户下的单个应用。禁用保留数据；卸载会删除该用户的应用数据。预装应用的“为当前用户卸载”不删除系统分区 APK；仅保留安装包的系统应用可恢复安装，不恢复已删除数据。
- **只读保护**：Quiet TV、自身验证组件、关键系统组件及未经当前机型确认的预装包不提供系统状态修改按钮。
- **操作记录**：保存操作前后状态和结果，是配置记录，不是应用数据备份。连接中断时先重新连接并刷新，不重复点击卸载。

Dock 编辑不依赖 ADB。禁用的 Dock 应用暂时隐藏并保留顺序，启用后恢复；核对卸载成功后移除其快捷配置。设置在电视本地保存，APK 更新不会覆盖用户的 Dock，包括主动清空的配置。

开发源码新增“应用列表 → 更换封面”：同网手机扫码后选图、拖动或缩放裁剪，上传后在电视确认才应用。“恢复默认”需确认，使用应用当前自带封面。推荐 720 × 406 px，最低 360 × 203 px；JPG、PNG、静态 WebP，单张不超过 2 MB，可用 AI 按尺寸辅助制作。无需 ADB；应用原始图标和系统操作保护保留。五种筛选常驻列表上方，ADB、更多、关于在右上角并排。此功能尚未包含在已发布的 1.1.2 安装包中，详见[自定义应用封面](APP_MANAGEMENT.md#自定义应用封面)。

首页排序同样不依赖 ADB，顶部 Dock 保持独立。保存自定义顺序后，新出现的应用追加到末尾；应用改名或更新保持位置。禁用或加入 Dock 时保留原位置记录，恢复显示后按记录排列；卸载后清除记录。恢复默认后，壁纸设置、桌面设置和应用管理在前，其余按名称排列。配置保留在本机，正常覆盖更新不清除；真实电视的遥控、重启与更新保留情况需在对应设备上验收。

实机证据与支持边界见[管理功能验收](APP_MANAGEMENT.md)。

## 开机广告管理

在“应用管理 → 更多”进入开机广告管理，按本机匹配的适配规则检测。仅在规则与实际服务状态满足条件时开放停用和恢复，恢复以操作记录中的原状态为准；未匹配设备保持只读。当前尚无通过 Quiet TV 真机验收的开机广告规则，不承诺移除所有品牌广告，详见[应用管理](APP_MANAGEMENT.md)。

## 语言与初始配置

修改 `app/src/main/assets/launcher.json` 后重新构建并更新安装：

```json
{
  "language": "zh",
  "greeting": "time",
  "dock": ["com.trim.tv", "com.xiaodianshi.tv.yst", "top.yogiczy.slcs.tv", "com.xunlei.downloadprovider.hd"],
  "hidden": ["com.dangbei.TVHomeLauncher", "com.android.tv.settings", "com.sony.dtv.settings"]
}
```

这是当前索尼机型的配置示例，包名需按自己的已安装应用调整。`dock` 为首次迁移使用的最多五个应用包名，顺序从左到右；首次迁移后请使用界面管理，修改资源不会覆盖已保存的 Dock。`hidden` 只影响桌面显示，不禁用包。`language` 使用 `zh` 或 `en`；`greeting` 使用 `time` 或 `home`。当前代码不支持提示词中规划的 `system` 自动语言模式。

## 壁纸

在“全部应用”中进入“壁纸设置”。左右移动预览，确定或点击“使用这张壁纸”保存选择；普通模式按返回取消未应用的预览并回到桌面。管理模式按返回先退出管理，已完成的删除不会撤销。

- **默认颜色主题**：纯黑背景加主题色光晕，随选中应用换色，始终保留且不可删除。
- **图片与轮播**：确认一张图片会关闭轮播；开启轮播后，保留的内置图和用户图片每 5 分钟切换一次。打开选择页或离开桌面时暂停，回来后重新计时。
- **每日壁纸**：默认颜色主题后的“每日壁纸”卡片，左右聚焦仅预览，按确定或单击直接应用并开启每日更新，无需另开开关。“每日设置”可选择必应国区或搏天风景；选来源后点“确认来源”直接应用，取消或失败保留原来源和壁纸。“检查更新”只检查所选来源，不会自动启用或切源。每日模式与本地轮播互斥；选择本地壁纸后退出每日模式。
- **每日更新与离线**：桌面打开、跨日或网络恢复时按需更新，成功保存新图后再切换；断网保留缓存。搏天每天固定一张，不做随机连播。每日入口不能删除，也不计入上传容量。来源接口与图片地址均需网络可达，不保证所有运营商或电视固件可用。
- **管理**：在图片上长按遥控器确定，或点击右上角“管理”后选择单张删除，并在确认弹窗中决定是否删除。内置图片从列表和轮播中移除，可通过“恢复内置壁纸”找回；用户图片删除电视中保存的副本。删除当前固定图片后回到默认颜色主题，轮播当前图片被删除时切到下一张；不足两张图片时自动关闭轮播。
- **上传**：点击“上传壁纸”，同一局域网中的手机扫码，或电脑打开电视短地址并输入 6 位连接码。选择图片或 MP4 视频，成功后在电视按返回，再预览并应用。上传不会自动切换壁纸；支持 Wi-Fi 和网线，无需 ADB、账号或云端服务。

支持 JPG、PNG、静态 WebP；单张最多 20 MB、4000 万像素，最多 20 张用户图片，处理后总容量最多 50 MB。新保存的显示图按应用实际显示尺寸处理，最长边不超过 3840 像素；低内存或内存档位低于 256 MB 时最多 1920 像素，自动校正方向，按等比铺满、居中裁切显示；透明区域以黑色背景呈现。电视只保留处理后的图片，不影响手机或电脑原图。HEIC 照片请先转换为 JPG。

动态壁纸是尚未发布的开发源码功能，默认关闭。进入“动态壁纸”分类，移动焦点只显示封面，按“预览”才播放；“使用动态壁纸”等首帧成功后保存。关闭开关或删除当前视频，恢复此前的图片、每日壁纸或轮播状态。视频静音、单个循环、不参加图片轮播；离开桌面或熄屏时释放播放器。播放失败可主动预览重试。

视频限 MP4、30 FPS、每个 100 MB，最多 10 个，视频及封面总计 500 MB，并检查实际剩余空间和解码能力。共同基础为 H.264 8bit SDR；安卓 5+ 按能力接收 HEVC Main 8bit SDR 和最高 4K30，安卓 4.4 本批限 H.264 1080p 内。暂不支持 HDR、10bit、60 FPS、GIF、动态 WebP 或壁纸工程。建议横屏、10～60 秒、首尾可衔接的素材。4K 标记仅表示素材规格，完整输出、持续流畅度、屏保与待机须对应电视验收；缩小显示不减少原视频解码负载，弱设备请上传真实的低规格版本。旧系统的 4K 视频可能使用占位封面；手机无法预览 HEVC 时可上传后在电视确认。

上传服务仅在电视上传弹窗打开期间运行，关闭、进入后台、网络地址变化或空闲 10 分钟后结束；旧二维码和连接码随会话失效，重新连接后刷新。连接码连续输错 5 次会暂停验证 30 秒。连接失败时请检查访客网络／设备隔离，并尝试在系统浏览器中打开短地址。上传失败或空间不足不会替换已有壁纸。

覆盖更新保留壁纸与移除状态；卸载或清除 Quiet TV 数据会移除用户图片。旧版本的壁纸选择和轮播模式在首次启动时迁移。管理与上传已包含在 1.1.2 两档下载中；本次索尼截图仅展示页面，完整上传、删除恢复及升级保留验收仍待完成。图片来源与使用边界见[第三方资源说明](../THIRD_PARTY_NOTICES.md)。

## 桌面设置

在“全部应用”中进入“壁纸设置”后面的独立“桌面设置”模块。时间与日期、天气保持独立开关；“右侧快捷按钮”分组中的信号源、网络、设置可分别显示或隐藏，默认全部显示。隐藏后其余按钮按原顺序靠右排列，遥控器跳过隐藏按钮。返回首页后生效并自动保存，正常覆盖更新保留选择；原来的右侧按钮总开关选择会作为尚未单独设置项的默认值。即使三个按钮全部隐藏，仍可从“全部应用 → 桌面设置”重新开启。已有自定义排序会将新增入口放到壁纸设置后；之后可在首页排序中调整。已发布的 1.1.2 安装包提供原总开关，本次独立显隐尚未发布，真实电视的遥控、重启与覆盖更新保留需对应设备验收。

“桌面显示 → 显示应用标题”控制 Dock 上方当前选中应用的大标题，默认开启。关闭后 Dock 位置保持不变；返回首页即生效，选择保存在本地，重启后保留。此开关尚未包含在已发布的安装包中。

## 首页问候语（开发源码）

在“全部应用 → 桌面设置 → 桌面显示 → 首页问候语”编辑。“显示问候语”开关可独立隐藏文字，天气和时间仍按各自设置显示。关闭时保留原文字，重新开启即可恢复。

使用遥控器选中输入框，通过系统输入法输入；电视已安装拼音输入法时可输入中文。也可选择“手机扫码输入”，手机与电视连接同一局域网，扫码后编辑并发送；无法扫码时，在手机浏览器打开电视显示的地址并输入连接码。发送只回填电视编辑框，仍需在电视上选择“保存”；“取消”或返回均丢弃本次开关与文字改动。

留空并保存后按时间显示早上好、下午好或晚上好，长文字在首页单行省略，编辑时保留完整内容。未编辑过的旧固定欢迎配置继续显示“欢迎回家”。扫码连接在返回编辑、应用进入后台、网络地址变化或空闲 10 分钟后失效，每次只接收一次发送。文字仅保存在电视本地，无需账号或云服务。此功能尚未包含在上方已发布的 1.1.2 安装包中。

## 首页天气（开发源码）

问候语右侧同一行显示静态天气图标、当前温度、天气描述与城市，时间日期位置不变。在“全部应用 → 桌面设置 → 桌面显示”开关天气；左侧“天气”分类提供自动定位、选择城市、刷新天气与服务说明。关闭自动定位时固定已识别的城市；尚无可固定城市时先选城，取消则保留自动定位。手动选城会关闭自动定位。天气隐藏时仍可调整城市偏好，但不会定位或刷新天气。设置不依赖 ADB，右侧系统设置入口保持原样。此功能尚未包含在上方已发布的 1.1.2 安装包中。

使用 [UAPI 免费天气接口](https://uapis.cn/docs/api-reference/get-misc-weather)，免注册、免密钥，无需自建服务器。启用天气后，客户端通过 HTTPS 查询；已有近似位置权限且系统网络定位可用时，最多等待 5 秒并将坐标保留两位小数后查询地区，否则按网络出口 IP 推测城市。手动城市优先，不会被自动定位覆盖；IP 位置可能受代理和运营商影响，可手动纠正。只有在天气设置中选择自动定位时才为天气请求近似位置权限，拒绝仍可使用 IP 推测或手动城市。服务会处理请求 IP 及所查询地区，见 [服务隐私与条款](https://uapis.cn/docs/getting-started/privacy-policy)。

首页可见时约每 30 分钟刷新，返回首页优先使用缓存，离开首页停止定位及定时请求。首页只显示天气图标、温度、天气描述与城市；正在刷新或更新失败时保留有效缓存，不追加“未更新”等状态文字。尚无有效数据、缓存超过 6 小时或关闭天气时，首页隐藏天气区域。超过 1 小时的数据状态、刷新失败原因及更新时间可在天气设置中查看；无法识别接口数据时间时，以缓存获取时间控制保留期，设置页明确显示数据时间未提供。不以默认城市或 0°C 代替真实结果。免费服务有动态限流，不承诺永久可用；429 按服务等待时间与至少 30 分钟暂停刷新，不自动密集重试。

安卓 4.4 仅为该 HTTPS 连接启用 TLS 1.2，保留系统证书和主机名校验，不回退到明文 HTTP；旧固件证书库及各品牌真实定位能力仍需真机验证。天气图标是包内原生静态绘制，无视频、WebView 或持续动画。

## 信号源、网络与设置

信号源菜单来自电视真实 TV Input 列表。当前索尼机型列出 HDMI 1–4、AV 和电视直播；其他设备以实际输入为准。频道为空时提供设置入口，不自动搜台。网络按钮打开网络设置，另一个设置按钮打开系统设置。

1.1.2 标准档会在标准输入服务缺失、受限或返回空列表时，检查已知的原厂信号源面板。只有实际存在、已启用且允许 Quiet TV 调用的系统组件才会作为入口；只有一个可用面板时直接打开，多个面板时显示选项。有正常输入列表时保留该列表，并提供可用的系统信号源入口。BYINTEK U4 上游报告的虚假标准列表采用原厂面板优先策略。标准切换调用报错时，可选择系统信号源面板；画面黑屏但调用未报错时，可返回菜单手动选择系统入口。

没有可用入口时显示具体原因并提供系统设置，不能据此判断电视没有 HDMI／AV。面板被禁用或权限受限时不会自动启用组件或修改权限。海信、TCL、BYINTEK 的候选入口与验收边界见[信号源兼容](COMPATIBILITY.md#信号源兼容)。1.1.2 标准档包含此回退；安卓4.4档使用系统设置／遥控器。存在入口不代表目标电视已经可以切换。

有线网络已验证。Wi-Fi 名称依赖位置权限与定位开关，当前未完成实机切换验收。应用能打开不代表账号、播放、声音或第三方服务已经验收。

## 更新与恢复

按[安装指南](INSTALL.zh-CN.md)重新构建和更新 Quiet TV。第三方应用通过各自渠道更新。系统精简的恢复依赖目标设备自己的原始备份和 journal；不要在其他电视运行仓库已有的索尼恢复清单。

### 1.1.2 的入口与图片兼容

1.1.2 补充部分厂商应用和设置入口，首页、常用应用选择及排序使用同一应用目录。已禁用、未导出或需要未授予权限的入口不显示；不是将全部系统包都变成可启动应用。

新上传图片按应用实际显示尺寸与内存条件处理，最高保留 3840 像素长边；低内存设备上限 1920。已有图片保持原样，需要更高清版本时可重新上传原图。高清源图、4K 面板和应用实际以 4K 渲染是不同条件。

部分 TCL 系统可显示快捷信号源面板；两个已知小米/红米型号有限定端口修正。未匹配设备继续用标准列表或系统面板。实际画面与适用范围见[兼容说明](COMPATIBILITY.md#本轮源码兼容改进)，1.1.2 标准档包含这些路由；安卓4.4仍使用系统设置／遥控器。
