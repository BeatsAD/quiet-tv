# 使用指南

[English](USAGE.en.md) · [返回首页](../README.md)

## 遥控器

| 操作 | 行为 |
| --- | --- |
| 左／右 | 在当前行移动，到行末停止 |
| 上／下 | 在快捷按钮、Dock 与应用网格之间逐行移动 |
| 确定 | 打开选中的应用、系统入口或壁纸设置 |
| 网格中按返回 | 返回 Dock |
| 应用中按 HOME | 回到 Quiet TV，恢复上次焦点 |

最后一行不足四项时，焦点落到最近的有效列。焦点会保存到本地，桌面进程重启后恢复；本次索尼机型已完成一次整机重启，确认自动进入桌面及 Dock／壁纸配置保留；长时间运行仍待验收。

## 应用管理与 Dock

在首页下方“全部应用”选择“应用管理”。顶部仍保留信号源、网络和系统设置。

- **Dock 管理**：最多 4 个。选位置后可替换、移除，或进入左右排序；确定保存，返回取消。空位从已安装、已启用且有启动入口的应用中添加。移除只改变快捷入口。
- **首页排序**：在“应用管理 → 首页排序”调整首页下方应用，包括壁纸设置和应用管理入口。确定拿起，方向键移动，再次确定放下；返回取消本次移动，点击“保存顺序”才会生效。离开未保存页面时可保存、放弃或继续编辑。“恢复默认”也需保存后生效。
- **应用列表**：左侧列表、右侧详情；可按应用名或包名搜索，并筛选全部、用户、预装、已禁用或可恢复的应用。
- **ADB 设置**：点击右上状态按钮，开启电视网络调试后填写端口（传统 TCP 默认 5555），在电视弹窗允许 QuietTV。首版仅适配当前索尼固件的本机 TCP；配对码式无线调试尚未支持。
- **系统操作**：只针对当前 Android 用户下的单个应用。禁用保留数据；卸载会删除该用户的应用数据。预装应用的“为当前用户卸载”不删除系统分区 APK；仅保留安装包的系统应用可恢复安装，不恢复已删除数据。
- **只读保护**：Quiet TV、自身验证组件、关键系统组件及未经当前机型确认的预装包不提供修改按钮。
- **操作记录**：保存操作前后状态和结果，是配置记录，不是应用数据备份。连接中断时先重新连接并刷新，不重复点击卸载。

Dock 编辑不依赖 ADB。禁用的 Dock 应用暂时隐藏并保留顺序，启用后恢复；核对卸载成功后移除其快捷配置。设置在电视本地保存，APK 更新不会覆盖用户的 Dock，包括主动清空的配置。

首页排序同样不依赖 ADB，顶部 Dock 保持独立。保存自定义顺序后，新出现的应用追加到末尾；应用改名或更新保持位置。禁用或加入 Dock 时保留原位置记录，恢复显示后按记录排列；卸载后清除记录。恢复默认后，壁纸设置和应用管理在前，其余按名称排列。配置保留在本机，正常覆盖更新不清除；真实电视的遥控、重启与更新保留情况需在对应设备上验收。

实机证据与支持边界见[管理功能验收](APP_MANAGEMENT.md)。

## 语言与初始配置

修改 `app/src/main/assets/launcher.json` 后重新构建并更新安装：

```json
{
  "language": "zh",
  "greeting": "time",
  "dock": ["com.trim.tv", "com.xiaodianshi.tv.yst", "top.yogiczy.slcs.tv", "com.xunlei.downloadprovider.hd"],
  "hidden": ["com.dangbei.TVHomeLauncher", "com.android.tv.settings", "com.sony.dtv.settings"]
}
```

这是当前索尼机型的配置示例，包名需按自己的已安装应用调整。`dock` 为首次迁移使用的最多四个应用包名，顺序从左到右；首次迁移后请使用界面管理，修改资源不会覆盖已保存的 Dock。`hidden` 只影响桌面显示，不禁用包。`language` 使用 `zh` 或 `en`；`greeting` 使用 `time` 或 `home`。当前代码不支持提示词中规划的 `system` 自动语言模式。

## 壁纸

在“全部应用”中进入“壁纸设置”。左右预览，确定应用，返回取消并恢复原状态。

- 默认壁纸：纯黑背景加主题色光晕，随选中应用换色。
- 固定风景：选择并确认一张图片，关闭轮播。
- 自动轮播：上移到轮播开关，按确定启用；桌面前台每 5 分钟切换一次。

离开桌面或打开选择页时暂停轮播，回来后重新开始 5 分钟计时。选择和模式保存在本地。图片来源及使用边界见 [第三方资源说明](../THIRD_PARTY_NOTICES.md)。

## 信号源、网络与设置

信号源菜单来自电视真实 TV Input 列表。当前索尼机型列出 HDMI 1–4、AV 和电视直播；其他设备以实际输入为准。频道为空时提供设置入口，不自动搜台。网络按钮打开网络设置，另一个设置按钮打开系统设置。

有线网络已验证。Wi-Fi 名称依赖位置权限与定位开关，当前未完成实机切换验收。应用能打开不代表账号、播放、声音或第三方服务已经验收。

## 更新与恢复

按[安装指南](INSTALL.zh-CN.md)重新构建和更新 Quiet TV。第三方应用通过各自渠道更新。系统精简的恢复依赖目标设备自己的原始备份和 journal；不要在其他电视运行仓库已有的索尼恢复清单。
