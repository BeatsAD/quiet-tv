# 包分类记录样例 / Package classification example

与 [CSV 样例](package-inventory.example.csv) 配套。每一项应记录包名、用途、原始状态、当前状态与证据；用途分类不代表可以禁用或卸载。

Use alongside the [CSV example](package-inventory.example.csv). Record package, purpose, original state, current state, and evidence. Classification does not authorize disabling or uninstalling a package.

- `com.example.placeholder`：文档占位包，不对应真实应用；未执行任何操作。
- `com.example.placeholder`: a documentation placeholder, not a real app; no operation performed.
