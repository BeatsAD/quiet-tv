# 首次设置模拟演示

当前候选：`1.1.0 / b7 / debug`。按用户最新要求，首次设置及恢复入口先展示**纯模拟交互**，直接复用已确认网页原型；不连接 ADB，不执行真实默认桌面切换、禁用、卸载、恢复或重启。

## 使用

应用管理 → 更多 → 首次设置（模拟）。旧首次设置组件及恢复入口也映射到模拟页，避免从旧任务返回真实执行页面。

- 方向键移动焦点，确定激活；原桌面三选一、六项卡片、弹窗关闭和折叠连接设置均可到达。
- 输入框先选中，按确定进入编辑；返回结束编辑，再用方向键移出。折叠内的隐藏字段不参与导航。
- 返回关闭弹窗或回到上层；在模拟桌面再按返回退出演示。右上角始终有退出入口，菜单键可打开演示工具。
- 演示工具提供标准切换、传统 ADB、无线配对、暂未适配情境，以及重新体验、模拟 HOME、模拟重启和恢复中心。
- 推荐名称和应用状态均为原型演示数据，与电视实际扫描结果无关；六项初始可选。模拟连接、系统确认及成功提示不代表真实电视状态。

模拟状态仅保存在 WebView 同源 localStorage；重新体验只重置该演示数据，模拟重启保留模拟配置并断开模拟连接。真实 Dock、壁纸、HOME、应用状态及原生设置基线不由演示修改。

## 实现和验证

APK 打包同一份 `SetupExperience.jsx`，不再重新制作另一套原生近似界面。页面全屏显示，评审工具收进演示工具；旧版 WebView 的容器宽度单位在全屏构建中等价转换为视口宽度单位。

演示资源全部随 APK 离线提供。WebView 禁止网络加载、文件与内容访问、弹出窗口；仅从固定本地域名映射打包资源，CSP 禁止网络连接，不提供 JavaScript 原生操作桥接。退出 URL 仅关闭演示。

构建会调用本地 Node/Vite，使用原型已锁定的依赖；首次使用该工作副本需先在 `prototypes/app-management` 安装锁定依赖。输出不清空目录，不覆盖历史 APK 归档。

专用模拟器检查：`scenario setup-demo`。覆盖真实方向键及确定／返回键、各屏和弹窗焦点图可达性、输入法实际数字输入、授权取消与自动继续，以及模拟禁用／卸载／恢复。执行前后核对真实 HOME、包禁用清单及原生设置记录不变。旧 b5 原生 UI 场景在当前模拟候选中不执行；历史结果见 [验证记录](SETUP_VERIFICATION.md)。

本次保留的真实原生实现不作为当前首次设置入口；恢复真实执行需要另行明确实施与设备验收范围。
