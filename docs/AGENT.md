# Quiet TV：给电脑 AI 的统一入口

你负责通过用户电脑检查电视，按用户意图完成安装、升级、适配修复或恢复。亲自执行命令并读取真实结果；没有终端能力就说明限制，不声称已操作。先读本页，再只读取当前分支。不要一次读取全部说明、脚本或机型规则。

## 用户复制的唯一请求

```text
请通过我的电脑配置和维护 Quiet TV，先读取：
https://beatsad.github.io/quiet-tv/agent.md
先检查电视；未安装时安装最新适配版，已有安装时按需升级或修复。
沿用有效接管方案，保持 ADB 常开，保留应用数据和原桌面恢复记录。
恢复原桌面仅在我明确要求时执行；需要我操作电视时提醒我。
若有未完成任务，先读取原记录并核对现状再继续。最后说明完成项、未验证项和恢复方法。
```

用户可以追加“只检查”“只更新”或“恢复原桌面”。明确目标优先；已暂停不代表故障。基础试用是首装检查点，没有独立试用路线，不让用户选择脚本。

## 先做什么

先告诉用户：“我先检查电脑工具和电视连接，确认已安装版本、接管状态和恢复记录，再决定下一步。”

已有任务先取得原目录并 `resume`，复用原工具；新任务再读[连接、检测与工具准备](agent/connect.md)，确认电视、ADB 授权和当前用户。无连接时指导电视系统操作，不承诺解锁固件调试入口。系统只读检查先于应用查询，不通过启动应用掩盖开机问题。

电脑公开文件由资源助手按校验值镜像优先、失败回原站，索引／API直连原站。ADB现场工具先检查已有连接，再按实际系统给常规方法；菜单不符才定向检索，已开启但连不上转查连接。

按[任务记录与中断继续](agent/session.md)建立私有任务。已有任务先 `resume`：重新核对同一设备、固件、用户、工具与说明版本，读取未确认步骤，不重复安装或写入。缺失原工具时先保留全部旧记录，说明无法安全继续，不能用新版本假装原任务。

## 根据意图和证据分流

| 条件 | 只读取并执行这一分支 |
| --- | --- |
| 明确恢复原桌面 | [恢复](agent/restore.md)，不先安装或升级 |
| 只检查、目标不明或安装状态未知 | 保持只读；缺失结果不算未安装 |
| 未安装且用户要使用 Quiet TV | [安装](agent/install.md)：先安装试用，用户基础操作通过后再配置 HOME 和必要 ADB |
| 已安装且允许更新 | [升级](agent/update.md)，匹配包名、签名、系统与构建号，保留数据及既有路线 |
| 已安装但配置异常，用户要求修复 | [维护](AGENT_ADAPT.zh-CN.md)，沿用路线，先检查后修复 |
| 已安装且正常、无适用更新 | 报告无需操作，不初始化、不重复配置 |

安装、升级、修复可以先后发生，不能只凭品牌选择路线。已有正常配置不重跑 `takeover`；仅更新保留原 ADB 选择，默认请求的 ADB 保持可在能力支持时独立配置，不能顺带启用已暂停守护。未知固件按实际能力检查；只有命中专项问题才读 [HOME/ADB](agent/home.md)、[TCL 安装](agent/tcl.md)、[信号源](agent/inputs.md)或[适配规则](DEVICE_ADAPTATION.zh-CN.md)。

按[任务工具](agent/session.md) `plan` 固定本次路线与必要验收；修复须注明问题领域，`repair` 仅处理 HOME／ADB。无需操作选择 `noop`，不启动安装器。脚本限制各路线允许的动作，用户不需要选择工具。

## 执行与结束

先简短说明本次动作、影响及记录位置；已有授权不重复询问。通过任务工具调用现有脚本，先预览再执行，保存原值并读回。应用禁用、原桌面恢复、电源测试按用户实际授权处理，不作为默认精简操作。

不卸载原桌面、不清数据、不刷机、不猜恢复值。出现失败或断连先读原始日志与现场，停止依赖该结果的写入；中断继续不是重试命令。

首次配置在路线稳定后按[遥控器逐键校准](agent/remote.md)依次采集 HOME、信号源和菜单键，试用并取得用户画面确认后保存；仅更新保留原映射。旧 APK 无接口时报告未校准。

按[验收与失败报告](agent/acceptance.md)逐项交付：实际 APK、HOME、守护、ADB、实体按键、重启、冷启动、待机及恢复方法。未测就是未测；ADB 开关打开不等于重启后网络可连接。交付私有任务目录，用户以后仍使用本入口继续或恢复。

先用现场工具发现外设候选，结合用户补充选择实际相关项目，不限品类；未知通道由Agent核对。用户结果用accept记录，发现、连接、实际可用分开。最后finish：必需项全通过才完成，缺证据待确认，能力受限部分完成，失败单列。不要重复索要仍有效的APK人工验收。

1.3.1 测试版已提供配套 APK，按实时索引选择安卓5及以上标准通用包或安卓4.0至4.4兼容包。旧 APK 缺维护接口时保留其支持的安装、守护和恢复路径，停止依赖新接口的操作；不临时构建安装包替代公开附件。
