# Quiet TV：给电脑 AI 的统一入口

通过用户电脑检查、安装、升级、修复或恢复，并读取真实结果；无终端能力须说明限制，不声称已操作。先读本页，再按分支读取，不通读全部说明和脚本。

## 用户复制的唯一请求

```text
请通过我的电脑配置和维护 Quiet TV，先读取：
https://beatsad.github.io/quiet-tv/agent.md
先检查电视；未安装时安装最新适配版，已有安装时按需升级或修复。
请识别品牌、机型、固件和安卓版本，完成开机及实体 HOME 接管。
允许在精确适配规则和恢复条件满足时禁用已确认的原桌面；先说明对象、影响和恢复办法，不精简其他系统应用。
沿用有效接管方案，保持 ADB 常开，保留应用数据和原桌面恢复记录。
恢复原桌面仅在我明确要求时执行；需要我操作电视时提醒我。
开机广告仅在我明确要求关闭时，按本机已验收方案单独处理并保留恢复记录。
若有未完成任务，先读取原记录并核对现状再继续。最后说明完成项、未验证项和恢复方法。
```

可追加“只检查”“只更新”“关闭开机广告”“同包名空壳接管”或“恢复原桌面”。明确目标优先；暂停不代表故障。基础试用是首装检查点，不单列路线，不让用户选择脚本。

## 先做什么

先按目标分流；只分析时不执行设备命令。现场检查前说明电脑工具、连接、安装状态及恢复记录的核对范围。

新任务读[连接、检测与工具准备](agent/connect.md)，确认电视、ADB 授权和当前用户。无连接时指导电视系统操作，不承诺解锁固件调试入口。系统只读检查先于应用查询，不通过启动应用掩盖开机问题。

资源助手按校验值下载公开文件，镜像优先、失败回原站；索引／API直连。ADB先查连接；未开启按[入口指引](agent/adb.md)优先对应型号，否则列出同品牌方法逐个尝试，缺固件不卡住；已开则查连接。

按[任务记录与中断继续](agent/session.md)建立私有任务。续办先 `resume`，核对同一设备、固件、用户、工具与说明版本及未确认步骤，不重复安装或写入。缺原工具时保留旧记录并报告无法安全继续，不用新版冒充。

## 根据意图和证据分流

| 条件 | 只读取并执行这一分支 |
| --- | --- |
| 明确恢复原桌面 | [恢复](agent/restore.md)，不先安装或升级 |
| 明确关闭开机广告或恢复广告修改 | [开机广告](agent/boot-ads.md)：优先官方渠道，技术操作须精确验收规则，不重新接管 HOME |
| 明确要求原厂同包名／同名空壳接管 | [空壳调查](agent/home.md#原厂同包名空壳中转候选路线)，按只读示例调查，不执行替换或删除 |
| 只检查、目标不明或安装状态未知 | 保持只读；缺失结果不算未安装 |
| 未安装且用户要使用 Quiet TV | [安装](agent/install.md)：先安装试用，用户基础操作通过后再配置 HOME 和必要 ADB |
| 已安装且允许更新 | [升级](agent/update.md)，匹配包名、签名、系统与构建号，保留数据及既有路线 |
| 已安装但配置异常，用户要求修复 | [维护](AGENT_ADAPT.zh-CN.md)，沿用路线，先检查后修复 |
| 已安装且正常、无适用更新 | 报告无需操作，不初始化、不重复配置 |

首次接管或 HOME 修复先按[品牌与路线检测](agent/brands.md)只读分流；不能只凭品牌选路线。已有正常配置不重跑 `takeover`；仅更新保留 ADB 选择及守护暂停状态。命中专项问题再读 [HOME/ADB](agent/home.md)、[TCL 安装](agent/tcl.md)、[信号源](agent/inputs.md)或[适配规则](DEVICE_ADAPTATION.zh-CN.md)。

按[任务工具](agent/session.md) `plan` 固定本次路线与必要验收；修复须注明问题领域，`repair` 仅处理 HOME／ADB。无需操作选择 `noop`，不启动安装器。脚本限制各路线允许的动作，用户不需要选择工具。

## 执行与结束

电脑 Agent 负责接管，不转交用户到应用设置页手动操作；仅对真实系统弹窗及实机验收请求配合。先说明动作、影响及记录位置，沿用授权，通过任务工具先预览、保存原值、执行并读回。路线受限按[品牌检测](agent/brands.md)继续核对，不猜菜单或按键；无路线报告接管未完成。禁用、恢复与电源测试沿用各自授权。

不卸载原桌面、不清数据、不刷机、不猜恢复值。出现失败或断连先读原始日志与现场，停止依赖该结果的写入；中断继续不是重试命令。

首次配置在路线稳定后按[遥控器逐键校准](agent/remote.md)依次采集 HOME、信号源和菜单键，试用并取得用户画面确认后保存；仅更新保留原映射。旧 APK 无接口时报告未校准。

首装试用通过、配置 HOME 前，按[系统入口测试](agent/inputs.md#电脑测试并保存系统入口)由电脑列出、试开并读回设置、网络和信号源入口，确认后保存。无入口时核对本机组件与协议，记录受限或待适配；安装成功不代表三项通过。

按[验收与失败报告](agent/acceptance.md)逐项交付：实际 APK、HOME、守护、ADB、实体按键、重启、冷启动、待机及恢复方法。未测就是未测；ADB 开关打开不等于重启后网络可连接。交付私有任务目录，用户以后仍使用本入口继续或恢复。

用现场工具和用户补充选择相关外设，不限品类；未知通道由Agent核对。用accept记录用户结果，区分发现、连接与实际可用。最后finish：必需项全通过才完成；缺证据待确认，能力受限部分完成，失败单列。不重复索要有效APK验收。

配套 APK 按实时索引选择；缺接口停止依赖步骤，不临时构建替代公开附件。
