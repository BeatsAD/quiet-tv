# Quiet TV v1.0.1（b3 · Debug 测试版）

面向国内电视机的适配与应用升级改造。本次发布当前 `main` 的安装包，保留版本号 **1.0.1**，将构建号递增为 **3**。旧的 b2 本地归档保留。

| 项目 | 内容 |
| --- | --- |
| 安装包 | `quiet-tv_1.0.1_b3_debug.apk` |
| 应用包名 | `home.quiet.tv` |
| 包内版本 | `versionName 1.0.1` / `versionCode 3` |
| 构建类型 | Debug，使用现有调试签名；作为预发布测试包提供 |
| 最低系统 | Android 12 / API 31 |
| 当前适配机型 | Sony KD-65X9000H / BRAVIA VH1，Android 12；其他机型待验证 |

## 更新内容

- **新增电视端应用管理**：查看应用名称、包名、版本和状态；支持搜索、筛选、刷新及操作记录。通过按需连接的本机 ADB 执行单应用启用、禁用、当前用户卸载与符合条件的系统应用恢复，关键组件保持只读。
- **新增四位置常用应用编辑**：支持添加、替换、移除及左右排序；确定保存、返回取消。应用禁用后保留原位置，重新启用后恢复显示。
- **统一管理界面**：应用列表与常用应用采用暗色玻璃材质、白色焦点描边和统一弹窗，优化遥控器在列表、详情和操作按钮之间的导航。
- **优化首页焦点与 Dock**：卡片选中框统一外扩间距，移除黑色衬边；Dock 托盘使用半透明玻璃背景，保留原有白框与放大效果。
- **规范安装包交付**：文件名包含版本、构建号和构建类型；本地保留不可覆盖的 APK 归档、SHA-256 和构建记录，安装核对单独记录。
- **更新依赖与项目资料**：保留构建工具依赖的安全版本约束，补充应用管理、兼容性与版本说明；仓库收录独立网页交互原型，原型不打入 Android 安装包。

## 安装与校验

下载本次 Release 的 APK 和同名 `.sha256` 校验文件，放在同一目录后执行：

```sh
shasum -a 256 -c quiet-tv_1.0.1_b3_debug.apk.sha256
```

更新安装须与原安装签名一致。不同电脑生成的 Debug 密钥可能不同；签名不匹配时请使用原密钥，保留已有设置。具体步骤见[安装指南](https://github.com/BeatsAD/quiet-tv/blob/v1.0.1/docs/INSTALL.zh-CN.md)。私密仓库的安装包仅对获授权账号开放。

## 验证范围与已知问题

- 本次包执行构建、包内版本和 APK 签名校验；本次发布未安装到电视。此前 Sony 设备的应用管理与界面验证记录见[管理功能](https://github.com/BeatsAD/quiet-tv/blob/v1.0.1/docs/APP_MANAGEMENT.md)和[原生改版](https://github.com/BeatsAD/quiet-tv/blob/v1.0.1/docs/MANAGEMENT_REDESIGN.md)，不等同于本次 b3 包的实机验收。
- 预装应用卸载／恢复仍待破坏性实机验收；其他固件和机型、长期运行及新式配对码调试未覆盖。
- 发布准备时，新增依赖触发 **15 条 Dependabot 告警：2 条严重、8 条高危、5 条中等**。其中 5 条涉及 APK 的 Bouncy Castle 依赖，其余 10 条来自不打入 APK 的网页原型工具链。实际影响尚待分析及修复，当前告警可在[依赖安全页面](https://github.com/BeatsAD/quiet-tv/security/dependabot)查看。
