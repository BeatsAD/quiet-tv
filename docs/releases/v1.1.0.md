# Quiet TV v1.1.0（b23 · ARM32 优化测试版）

本次提供已在一台 Android 12 / ARM32 电视上覆盖安装并核对哈希的优化测试包，保留 v1.0.1 历史发布。

| 项目 | 内容 |
| --- | --- |
| 安装包 | `quiet-tv_1.1.0_b23_benchmark_armeabi-v7a.apk` |
| 应用包名 | `home.quiet.tv` |
| 包内版本 | `versionName 1.1.0` / `versionCode 23` |
| 架构与最低系统 | ARM32 / `armeabi-v7a`，Android 12 / API 31 |
| 大小 | 4,761,581 字节，约 4.54 MiB |
| 构建与签名 | `benchmark` 优化测试包，关闭调试、启用代码及资源裁剪，沿用原测试签名 |

## 更新内容

- **缩小安装包**：按架构打包并启用 R8 与资源裁剪；相对同源码 26.43 MiB Debug 包缩小约 82.8%。包体缩小不等于已证明运行提速。
- **优化壁纸与首页刷新**：按显示尺寸解码壁纸、按需加载缩略图、复用封面缓存，普通返回不再重复扫描全部应用；保留原有壁纸、过渡和五分钟轮播。
- **改进首次设置与关于页**：原生两步设置保留先选择、后授权的顺序；关于页使用原生首屏，离线许可按需打开。
- **增强 HOME 异常处理**：切换后读取实际默认桌面，记录未完成操作；在原连接和恢复条件可核验时恢复原桌面状态，不自动重连或重放。
- **补充机型参考资料**：新增 30 份未验证参考记录，与可执行固件规则隔离，不按品牌直接开放系统操作权限。

## 安装与校验

下载 APK 和同名 `.sha256` 文件，放在同一目录后执行：

```sh
shasum -a 256 -c quiet-tv_1.1.0_b23_benchmark_armeabi-v7a.apk.sha256
```

APK SHA-256：

```text
3292566bcea6287a9c059a1b9935763cd0e6b8df26af850a4c0027c019031762
```

仅适用于支持 `armeabi-v7a` 应用的设备；仅支持 64 位应用的设备不能使用此包。本次未上传 API26 实验候选。

已有安装须使用相同签名覆盖更新，保留应用数据。签名不一致时应使用原签名构建包，不通过卸载或清数据绕过。安装与设备备份步骤见[安装指南](https://github.com/BeatsAD/quiet-tv/blob/v1.1.0/docs/INSTALL.zh-CN.md)。本包仍为测试签名预发布版本。

## 验证范围

- 本次 ARM32 包已在一台 Android 12 电视覆盖安装；已安装 APK 与发布文件哈希一致，HOME 键返回、壁纸与 Dock 显示正常。首次安装时间、UID、数据目录和原有禁用包集合保持，未执行卸载或清数据。非调试包的私有偏好未在安装后逐文件核对。
- Python 7 项、JVM 11 项检查通过；Lint 0 错误、24 条警告。功能代码在 API26/28/30/31/33 模拟器完成相关检查，最终 b23 在 TV12/13 模拟器完成升级数据保持及优化包入口检查，实际五分钟轮播通过。
- 其他品牌固件、低于 1GB 设备、长期稳定性、成功六位码无线配对及破坏性卸载／恢复仍待验证；机型参考记录不代表适配完成。
