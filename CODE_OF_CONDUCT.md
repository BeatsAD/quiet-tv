# 社区行为准则 / Code of conduct

欢迎不同经验、语言、背景和设备条件的贡献者。本准则适用于 Issues、PR、Discussions 及以本项目名义开展的协作。

- 尊重他人，围绕代码、设计和证据讨论；提出具体、可执行的反馈。
- 接受善意提问与不同意见，不做人身攻击、歧视、骚扰、威胁或持续干扰讨论。
- 尊重隐私，不公开他人的联系方式、账号、设备标识、私密聊天或未脱敏日志。
- 认领任务、评审和测试时如实说明进度与能力边界，不冒用他人身份或成果。

维护者可以要求修改不当内容、锁定讨论，或对持续违规者限制参与。处理时考虑上下文和当事人意见；涉及维护者自身的争议应由无利益冲突的维护者协助，有此条件时执行回避。

如遇违规，请通过 README [保持联系](README.md#保持联系) 中你能使用的私密联系方式联系 @BeatsAD。若暂时无法取得私密联系，可在 [Discussions](https://github.com/BeatsAD/quiet-tv/discussions) 提出不含事件细节的联络请求，再确认受限沟通方式。不要公开受害者信息或完整证据。本项目不承诺固定响应时限。代码安全漏洞按 [SECURITY.md](SECURITY.md) 报告。

## English

Contributors of all experience levels, languages, backgrounds, and device access are welcome. These rules apply to issues, PRs, discussions, and collaboration representing this project.

Be respectful and give actionable feedback about code, design, and evidence. Welcome good-faith questions and disagreement. Do not harass, discriminate, threaten, attack people, or repeatedly disrupt discussions. Protect others' privacy and be honest about authorship, progress, and testing.

Maintainers may request edits, lock discussions, or restrict participation for repeated violations, considering context and those affected. A maintainer involved in a dispute should seek help from an uninvolved maintainer when available.

Contact @BeatsAD privately through an available channel in the README's [contact section](README.en.md#lets-connect). If no private channel is available, request contact in [Discussions](https://github.com/BeatsAD/quiet-tv/discussions) without publishing incident details, then agree a restricted channel. Do not expose victims or full evidence. No fixed response time is promised. Report code vulnerabilities through [SECURITY.md](SECURITY.md).
