# 小米 Android 6 主页中转助手（实验）

[Quiet TV](../README.md)  [兼容范围](../docs/COMPATIBILITY.md)

独立 APK，当前仅允许在型号 `MiTV4-ANSM0`、API23（Android 6）上启用。用于原固件无法将 Quiet TV 持久设为 HOME 的情况。**尚未在目标电视安装或验收，不承诺固件会保留无障碍服务、发送主页事件或投递开机广播。**

主程序 b31 同时补充普通 `LAUNCHER` 入口，并在小米设备上优先尝试系统自带的小米设置和 Wi-Fi 页面。候选组件必须已安装、启用、对外开放且调用权限可用；小米设置包还须为系统应用。Wi-Fi 专页不可用时尝试小米设置主页，再回退标准设置。缺少入口时显示提示，直接解析到 HOME 的入口不会启动。上游线索见 [PR #129](https://github.com/Gathin23/cleanyourtv/pull/129) 和 [小米设置记录](https://github.com/Gathin23/cleanyourtv/blob/main/docs/devices/xiaomi-mitv-mftr0-freeguy.txt)，其他型号的记录不能代替本机验收。

## 工作方式

- 首次安装默认暂停。用户从本机查询到的 `com.mitv.tvhome` 系统 HOME 候选中明确选择原主页，随后手动开启助手的无障碍服务并点击“启用中转”。
- 无障碍服务只接收该包的窗口状态事件，精确匹配保存的主页类名后打开 Quiet TV。设置、信号源或对话框等不同类名不会触发。若固件报告的窗口类与 HOME 组件不一致，当前助手不会猜测匹配或扩大到整个包，需要补充实机信息。
- 收到 `BOOT_COMPLETED` 时，仅在启用状态、目标机型、原主页仍可用及无障碍已开启等条件满足后尝试打开 Quiet TV。失败即暂停中转，没有轮询、后台重试或强制保活。
- 助手不读取屏幕内容，不过滤按键，不联网，不修改默认 HOME、系统属性或原桌面的启用状态。系统默认项可能仍显示小米，切换可能短暂闪现原桌面。

## 构建

按主项目 README 配置 JDK 与 SDK，在仓库根目录执行：

```sh
./gradlew :app:assembleDebug :xiaomi-home-helper:assembleDebug :xiaomi-home-helper:lintDebug -PquietXiaomiHelper=true --console=plain
```

输出为 `app/build/outputs/apk/debug/app-debug.apk` 和 `xiaomi-home-helper/build/outputs/apk/debug/xiaomi-home-helper-debug.apk`。助手仅在显式传入 `quietXiaomiHelper=true` 时参与构建，普通 Quiet TV APK 不包含该无障碍服务或开机接收器。包名为 `home.quiet.tv.xiaomihelper`，版本为 0.1 / 1；不支持其他 Quiet TV 专用包名。

调试签名仅用于本地测试。主程序覆盖安装前须核对实际安装包的签名和版本，不通过卸载或清数据解决签名不一致。助手首次安装后须手动打开一次。

## 使用与验收

1. 保留原桌面，安装签名相符的 Quiet TV b31 和独立助手。确认原桌面的全部应用出现 Quiet TV 图标，并能手动打开。
2. 从 Quiet TV 分别进入“设置”和“网络”，确认显示真正的系统设置与 Wi-Fi 页面，而非原桌面。
3. 打开助手，选择检测到的原主页，点击“打开无障碍设置”。在电视系统里手动开启“Quiet TV 小米中转助手”，返回助手点击“启用中转”。无可用原主页或无障碍入口时停止中转设置，保留手动使用。
4. 从常用应用和设置按实体遥控器 HOME 键；确认返回 Quiet TV。打开系统设置、信号源和播放页面，确认助手没有误拉回。
5. 分别验证整机重启、断电冷启动、待机唤醒和无障碍服务是否仍保留。一次成功不代表其他项目通过。
6. 点击“暂停中转”，再次按 HOME，确认恢复原固件行为；随后可关闭系统无障碍开关。

暂停会立即阻止后续窗口事件和开机处理。也可在系统无障碍设置中关闭该服务；助手随后不再进行开机中转。无需卸载、清数据或恢复出厂。若 Quiet TV 缺失或启动被拒绝，自动暂停并保留原桌面。

## 验证边界

本地已通过主程序和助手的 Debug 构建与 Lint（零错误）、4 项中转策略单元测试，以及专用 API31 模拟器上的 9 个设置路由场景、安装后普通应用入口查询、助手默认暂停／非目标设备保护／开机无操作和原生设置页启动检查。设置路由检查使用模拟组件，未启动小米厂商设置。主程序优化包还通过构建、签名校验及同一模拟器安装启动检查。

本机的策略单元检查、组件路由模拟和通用 Android 模拟器只能验证代码分支，不能证明这台小米固件的无障碍持久性、实体 HOME、开机、待机、Wi-Fi 或信号源可用。目标电视不在身边，以上真机项目均待验收。
