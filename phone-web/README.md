# QuietTV 手机扫码设置

文件传输助手可添加为首页按钮，电视全屏展示扫码连接与文件列表。二维码复用本网页的授权连接，通过 `#tab=tools&tool=files` 直接进入文件传输；已有手机设置连接继续使用。电视发送文件会在本网页打开对应文件，接收、删除和传输进度沿用同一配置域同步。本地存储与 U 盘浏览的是电视可读取或已授权的实际目录，保留目录授权边界。

儿童模式统一开关保留各应用规则与已使用额度。答题支持六科及一至六年级，统一按所选科目、年级的全部知识点出题；“自定义出题”位于科目内，可勾选题目、编辑或逐题删除。题目只含题干、四个选项和一个正确答案。本轮使用冻结副本，新设置从下轮生效；答错和超时不会放行，家长验证后可以跳过。立即答题独立于定时答题开关，仍受总开关、计时服务及观看额度限制。

电视儿童模式内的二维码复用现有手机网页连接，普通手机扫码即可打开网页，并通过 `?tab=child` 直接进入儿童模式。各浏览器首次输入电视显示的配对码，并建立独立连接，修改和立即答题仍需短时家长验证。“已连接手机”可结束网页连接，也可打开独立的手机助手绑定二维码、撤销已有助手授权或停止助手服务。

答题设置只保留间隔、科目、年级及按需出现的自定义题目入口；插画自动跟随每道题的科目，旧版指定的知识点及固定插画不再覆盖此行为。答题插画源文件位于 `app/src/main/assets/child-quiz/artwork/`，全部由 SVG 路径组成，由电视答题页直接绘制。休息屏保预览来自实际屏保素材。

生产网页由电视局域网服务提供，入口为 `http://电视局域网IP:8766/`。微信和普通浏览器扫同一个码，首次打开时在网页输入电视显示的 8 位配对码。连接后可收藏或复制该网址。电视 IP 不变、Quiet TV 已启动且浏览器保留授权时，重启后从收藏直连。电视端“解除全部配对”会撤销已有授权，各浏览器可在原地址重新配对。从 2.0.6 升级时，旧的 `.local` 收藏或旧 IP 无法打开，请在电视重新扫码，完成配对后收藏新地址。网页资源随 APK 提供。

```sh
npm ci
npm run check
npm run build
```

固定依赖和本地静态资源构建至 `app/src/main/assets/phone-settings/`。保留生成资源供普通 Android 构建使用；重新构建网页不会批量清空输出目录。Android 构建前使用 `python3 phone-web/check_assets.py` 核对源码与生成资源，避免打入旧页面。页面资源不依赖 CDN。

## 间距约定

扫码网页以 4px 为基础间距，常用 4、8、12、16、20、24px，使用对应的 `rem` 值实现。间距以可见内容的边界为准，避免外边距、行高和按钮高度重复叠加。

文字编辑弹窗采用以下紧凑间距，本次已应用于应用重命名弹窗；其他页面后续调整时按相同层级对齐，不将电视逻辑画布的尺寸直接套用到手机网页。

| 位置 | 间距 |
| --- | --- |
| 弹窗内容内边距 | 20px |
| 应用信息到表单标题 | 12px |
| 字段标题到输入框 | 8–12px，带行内操作时使用 12px |
| 输入框到原名称、字数统计 | 4px |
| 表单信息到底部按钮 | 16px |
| 两个底部按钮之间 | 12px |

输入框和按钮保留至少 44px 的点击高度。行内文字按钮可用透明伪元素扩展点击区域，不撑高文字行；扩展区域不得覆盖相邻输入框。弹窗按内容确定高度，保留键盘弹出后的视口适配。

API 使用固定入口下的同源相对地址。首次配对通过 `POST /pair` 提交电视显示的限时 8 位配对码。配对码不会出现在收藏网址中。持久 HttpOnly Cookie 保存一年，打开根地址时续期；电视只保存授权凭据的摘要，配对不随桌面备份导出。清理网站数据、更换浏览器或解除配对后需重新输入电视上的配对码。版本化快照包含会话代次、各配置域修订号和单调请求序号；普通参数自动提交，文字表单和儿童模式使用时长明确提交。超时先查询回执，不能盲目重放有副作用的操作。电视权限、家长验证和系统确认仍由电视业务模块执行。

操作回执独立记录请求结果、提交域的值及修订号，不再读取其他配置域。手机在响应和首次回执都丢失时保留原请求，前台轮询或恢复联网后继续核对；仅在电视确认未记录该请求时，使用完全相同的请求编号、序号和内容重发，由电视去重。结果未知时暂停后续写入，保留输入供核对；已拒绝的操作保留具体原因。连续调整只保留尚未发送的最后一次输入，旧请求和旧轮询的结果不能改写较新的输入或连接状态。

已授权页面在前台读取配置或回执时维持连接；转入后台停止轮询，10 分钟没有有效活动后本次连接过期，配对保留，重新打开收藏网址即可连接。背景图片等预览请求不延长连接。结束连接与解除配对分别处理，已结束的请求不会因同一浏览器重连而恢复执行。

固定入口使用电视当前局域网地址。端口 8766 被占用时显示错误。Quiet TV 主进程在用户已解锁且存在配对时恢复服务，地址变化后使用新地址。手机与电视须处于可互通的同一局域网。电视关机、进程未运行时网页不可用。各手机浏览器与厂商电视的实际兼容性仍须对应设备验收。

本地阶段记录与测试证据保存在工作树的 `output/phone-settings-development/`，不加入生产页面。原交互原型保留原状。

七个分类共用同一份电视状态：桌面显示、快捷控制、管理应用、儿童模式、工具、通用设置、更新与帮助。媒体与文件走有大小限制的原始流上传；文件、备份与诊断下载需要当前已连接的浏览器，并与上传共用单个传输名额。图库显示保存文件的实际尺寸/大小/时长，应用明确标注 APK 安装包大小。

`api/parent` 使用独立、禁止缓存的验证请求；密码和恢复码不进入普通快照或操作回执。儿童规则、应用保护、文件目录授权、信号源确认和更新安装均沿用电视端业务限制。

备份恢复先返回受理回执，再撤销本次连接并进入电视恢复等待页。已受理的恢复继续执行，不能以结束连接代替取消；恢复完成前新连接只读。重新打开收藏网址后读取正式恢复记录，受理状态不能当作恢复成功。所有普通参数冲突保留手机输入，供核对电视当前值后再决定。

页面切换只在导航时播放轻量过渡，后台状态刷新和实时保存不重播动画。浮窗使用浏览器原生动画完成阻尼回弹与退出，保留原生 dialog 的模态与键盘行为；关闭结束前阻止重复操作，并响应系统“减少动态效果”设置，无新增动画依赖。

常规应用读取仅在应用页显示加载和错误；有效目录可复用，手动刷新仍重新读取。任务携带独立的 domain/kind，反馈按当前页面或工具匹配，成功的目录读取不保留卡片。导出下载、备份导入核对及失败结果保留在对应工具内。

天气背景通过已授权的 wallpaper/__current-background 取得原生背景取样，页面可见时最多每 5 秒更新一次，上传或切到后台时停止取样。电视二维码面板使 HOME 暂停时使用与当前地点、天气缓存和昼夜设置一致的最近原生帧；无法取得时显示可重试提示，不以另画的天气代替。布局、模糊与亮度仍由手机按当前设置预览，此页面不是实时屏幕镜像。手机屏保预览只读，另有明确的电视屏保预览按钮。

固定设置定义或当前值缺失时显示读取不完整入口，并列出缺项；控件不再静默消失。图片模式的背景声音不属于必需字段，显示当前模式说明。家长验证、计时授权与实际设备验收仍按原有规则执行。

快捷控制编辑按普通按钮、滑杆、固定入口分区。普通按钮最多 8 个；背景明暗和音量各一次，统一置于按钮下方；桌面设置固定第九格，首页快捷控制固定保留。超额旧列表只在明确保存保留内容后更新，电视配置变化时保留手机草稿并提供冲突选择。预览从电视元数据读取短名称和矢量图标；音量按系统最大档位显示百分比，写入仍使用原始档位。

壁纸与屏保素材支持图片、视频混合多选，按顺序逐项上传，保留每项进度和结果；头像、应用封面与备份仍使用单文件流程。批量上传默认保存全部，可明确选择其中一项同时应用；已保存项不会因后续失败或取消而回退。结果未知时停止后续上传并提示核对，成功项不重复发送。

电视端的独立扫码上传页支持多选。普通壁纸可混选图片和视频，壁纸墙只接收静态图片。手机点击“上传并保存全部”后，每项成功回执表示已写入素材库；电视显示本次已保存列表。普通壁纸可选择一项使用，壁纸墙自动使用素材库中的自定义静态图片。扫码上传使用逐项请求编号与会话内回执查询，响应丢失后的重复请求复用原结果，避免重复入库。

上传前可逐项命名；素材库中已有的自定义图片和视频也可点击名称旁的编辑按钮改名。电视编辑按钮复用手机设置连接，扫码后直接进入该素材的重命名页，电视不弹出键盘。改名只更新显示名称，保持素材身份、文件、当前壁纸、轮换和屏保设置；冲突时保留输入，核对电视当前名称后再提交。

在“管理应用”中打开应用详情，选择“更换图标”，或在应用列表使用“批量换图标”。图标库复用电视素材清单、原生渲染和封面存储。候选只预览，确认后才替换；形状跟随桌面设置，圆形和方形仅提供纯图标、透明背景。素材清单为空时显示待接入，也可从手机上传图片并确认替换。替换与恢复校验当前图标，电视端已修改时保留候选并提示重新核对。图库测试素材只保存在本地验证资料中。

文件传输、备忘录和 Tailscale 入口位于独立“工具”分类。天气按“天气位置”“刷新天气”“来源与服务”组织，动态天气壁纸组件在桌面背景内下载并返回；天气背景状态、缓存回退与昼夜阶段从电视读取。应用列表直接标注首页应用。普通快捷按钮满额后可先选择候选，再选择要替换的按钮；保留原位置、桌面设置入口和快捷调节顺序，电视配置变化时停止此轮候选选择。

手机页面的通用图标采用与电视相同固定版本的 Lucide，保留手机触摸和底部弹层交互。“来源与服务”直接列出天气选项，服务信息按需展开；Open-Meteo 继续通过启用告知后设置。当前图片详情以标题、评分和简介纵向排列，保留来源署名与刷新入口。备份记录可直接导出含素材 ZIP 或确认删除，进入详情仍可导出 JSON 和恢复配置。

2.0.3 扫码网页与电视共用“第二屏隐藏首屏应用”设置，只隐藏首页实际显示的 Dock 应用，保留完整第二屏排序。首页预览在快捷控制仅聚焦显示时同步补位。图标库的“刷新图标库”执行电视端强制联网刷新，并显示实际任务结果，失败保留已有素材。

信号源主页面提供默认信号源、在桌面显示「看电视」、开机自动进入和更多设置。显示开关与电视共用，切换时会刷新桌面预览。检测、端口名称校正、诊断与恢复集中在更多设置。选择或校正后仍须测试并确认真实端口、画面和声音；开启自动进入再次校验保存目标、固件和开机应用，状态变化时保留当前配置。手机快捷控制在有保存目标或原厂菜单时直接请求电视打开，没有配置时进入手机配置页。请求发送不代表画面验收通过。
