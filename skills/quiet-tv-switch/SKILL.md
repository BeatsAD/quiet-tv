# 电视桌面切换助手

用用户能理解的语言推进操作。AI 完成电脑侧查询和命令；用户完成电视端授权、系统选择和真实遥控器验证。每次只给当前需要的电视操作，不把整页命令交给用户猜。需要实际反馈时等待回答，不能编造观察结果。

普通用户需要可执行终端命令的 AI 工具、自己的 Android 电视和电脑；网络 ADB 还需要可互访的局域网。没有终端权限时改为逐步引导，明确哪些步骤由用户执行。

## 先确定目标与授权

- “能不能用”“分析失败原因”只查询和解释；“帮我安装／切换”授权完成相应步骤。安装、切换、重启分别判断是否属于用户已授权范围，不重复索要已有授权。
- 普通安装与切换保留原桌面。只有已核对具体影响、恢复资格且属于用户授权的专项路线才可禁用；不卸载原桌面。恢复历史修改时以本机记录的原始状态为准。
- 先检查现有工具和设备连接，再询问缺失的信息。多设备时让用户选电视，所有后续 ADB 命令都指定同一个序列标识。不要自动选择唯一在线设备，它也可能是手机或模拟器。
- 用户已有 Quiet TV 或要求恢复时先读取现状，不先下载、覆盖安装或重新走初始化。

## 执行流程

安装或恢复前完整读取当前[Agent 安装说明](https://raw.githubusercontent.com/BeatsAD/quiet-tv/main/docs/AGENT_INSTALL.zh-CN.md)，版本选择、已有安装分流及失败报告以该说明为准；无法读取时告知用户，取得内容后再修改设备。已有安装的检查、修复、自检和本机信号源配置同时阅读[电脑适配指南](https://raw.githubusercontent.com/BeatsAD/quiet-tv/main/docs/AGENT_ADAPT.zh-CN.md)。具体命令见 [操作与恢复参考](references/operations.md)，进入相应阶段再阅读。

1. **连接与只读检测**：指导用户找到电视实际提供的开发者选项和调试入口。使用官方 Platform-Tools；按当前主机系统准备工具，不能预设本机路径、IP、端口、用户 ID 或无线配对能力。ADB 被固件禁止时说明限制；有手动 APK 安装和系统桌面选择入口时继续引导该路径。
2. **保存基线**：在首次启动或切换前，记录设备、固件、当前用户、HOME 候选、真实默认 HOME、原桌面组件及原始启用设置。可运行下方只读助手；不支持的查询必须记为未知，不能填默认值。记录保存在用户电脑的私有目录，不上传、不提交 Git。基线不是应用数据备份。
3. **选择并核验安装包**：使用用户指定的可信 APK，或通过本机终端实时读取 [最新版索引](https://beatsad.github.io/quiet-tv/latest.json)（自动附加本次时间的 `check` 参数并禁用缓存，包含测试版），结合 [兼容说明](https://github.com/BeatsAD/quiet-tv/blob/main/docs/COMPATIBILITY.md)。读取实际 APK 的包名、版本、最低 API、ABI、签名并核对发布方 SHA-256。普通主程序包名为 `home.quiet.tv`；实验专用包或助手不自动替代主程序，仅在用户明确选择且已核对配套关系时使用。包名和 HOME 组件均从实际 APK 声明核实。不能固定历史包、哈希或把本地未发布分支当成公开版本。无匹配下载包时说明原因，源码构建仅在用户选择该路径后进行，不能偷偷降低 minSdk。
4. **安装与试用**：满足安装条件后按授权保留数据安装，核对已安装版本及 APK 哈希。TCL／雷鸟出现校验拒绝时优先使用已发布 relay 的多屏互动／电视端安装路线，用户仍使用原安装请求。relay 不声明 HOME，复用现有守护；已装 relay 的更新保持形态，不自动覆盖为普通包，也不自动把已有普通包迁移为 relay。工具从实时 latest.json 的 tools 字段下载到同一目录并核对 SHA-256，流程见操作参考。品牌匹配不要求先提供固件号，临时停用安装器仅作为需要明确选择的独立方案。签名冲突或版本降级时停止覆盖安装；不通过卸载、清数据或强制降级解决。当前源码启动后直接进入桌面试用，不弹设置向导；实际旧版若仍显示引导，可选“暂不设置，临时使用”或跳过无关应用管理。验证遥控焦点、应用、设置和信号源入口；试用后按已有授权配置，缺少授权时再询问。预装应用管理与恢复原桌面仅按需进入。
5. **切换默认桌面**：先核对当前实际配置；已完成的直接 HOME、代理或中转继续沿用，不重新切换或要求用户完成向导。中转保留原 HOME 不等于失败。确需配置时由 AI 按已有授权完成，电视仅确认必要的系统选择或授权；新版电视端不显示桌面配置、守护或禁用入口，统一由电脑维护工具操作。ADB 路径先读取固件命令帮助，确认支持指定目标用户，再切换并读回 HOME。随后请用户按真实遥控器 HOME 键观察。被拒绝或返回原厂主页时停止依赖切换成功的修改。已有自动接管授权或另行守护授权、且实际 APK 包含电脑配置入口时，可按参考文档独立配置；无需等待内置 ADB 握手成功。其他异常按[Agent 问题排查](https://raw.githubusercontent.com/BeatsAD/quiet-tv/main/docs/AGENT_DIAGNOSE.zh-CN.md)采集证据。
6. **验收与恢复**：使用 `device_selftest.py` 保存修复前后报告，默认只读，按已有授权选择主动场景。交付本机适用的恢复方法；用户已授权重启且恢复途径确认可用时，完成一次整机重启验证。冷开机、重启和待机唤醒分别记录。发生故障时按授权恢复本次变更并读回状态，不盲目重试。

### 海信开机与 HOME 异常

识别到海信／VIDAA Android 电视开机先进入聚好看／原厂首页、实体 HOME 回原桌面或历史停用后黑屏时，必须读取并执行当前 Agent 安装说明的[海信开机接管排查](https://raw.githubusercontent.com/BeatsAD/quiet-tv/main/docs/AGENT_INSTALL.zh-CN.md#海信开机接管排查)。用户无需改写原安装请求。先区分 HOME 优先级／默认选择、厂商显式路由、API24+ 解锁前组件及存储、守护配置和启动广告；证据不足不能直接判定“权限不足，无法改造”。该分支是候选诊断路线，不自动安装实验助手、停用原桌面或替换动画；沿用已有授权、固件资格和恢复要求。

已有安装且用户要求开机进入 Quiet TV 时，按上述安装说明调用 `configure_boot_home.py` 的预览及 `--apply`；安装入口的 `takeover` 已自动接入。脚本实际设置默认 HOME，并在检测条件匹配时修正海信主页属性，保存逐步恢复记录；不止输出诊断建议。下载与恢复参数见[操作参考](references/operations.md#开机进入-quiet-tv)。

### 只读助手

相对路径以本 skill 所在目录为基准；换成当前主机的 Python 命令和实际路径。`TV_SERIAL` 必须来自用户选定的目标电视，`PRIVATE_RECORD` 是仓库外的新 JSON 文件路径。

```sh
python3 scripts/inspect_tv.py --serial "$TV_SERIAL" --output "$PRIVATE_RECORD"
```

脚本只读取当前已连接目标，不执行连接、配对、安装、启动、切换、启禁或重启；输出文件拒绝覆盖。它记录原始查询结果和缺失项，**不自动判定能否切换，也不构成禁用原桌面的资格证明**。后续首次启动前补全原桌面包的原始启用设置，缺失时不进行依赖该状态的修改。

## 操作边界

- 不 root、不刷机、不恢复出厂、不清数据、不卸载原桌面，不处理投屏、语音、更新等无关系统包。
- 不复制其他电视的包名、禁用清单、私有设备配置或 ADB 密钥。不修改 Quiet TV 的适配规则绕过未知固件只读保护。
- 固件返回 `cannot be home on user ...`、HOME 未读回、目标用户改变或连接丢失时，先查询现状并解释，再决定下一步；不能先禁用原桌面试错。
- 应用已启动、`Success`、HOME 解析、模拟 Home 键、真实 Home 键和重启验收是不同证据。上游实现、源码存在和旧版本验收也不能代替当前包在当前电视上的结果。
- 普通 APK、skill 和电脑 ADB 工具不能自动解开厂商关闭的调试入口；没有通用强制接管承诺。兼容守护仅在用户授权且实际安装包包含对应能力时配置；配置成功、服务绑定、系统 HOME 与真实按键结果分别核验。历史 APK 不随新源码获得守护能力，不能将实验功能当作厂商验收通过。

## 向用户交付

用简短结果表分别报告：APK 来源与校验、安装、默认 HOME 读回、真实遥控器 HOME、整机重启、重启后网络 ADB 重连、冷启动、待机唤醒、信号源画面、原桌面是否保留／禁用、恢复方法。状态用“完成／失败／未验证／未执行”，不要把部分完成报为全面兼容。

给出私有记录的位置及本机恢复步骤；公开反馈只包含脱敏型号、系统／固件与应用版本、复现步骤和相关错误片段，不附 IP、序列号、配对码、密钥或完整设备转储。

机型规则已迁入电脑工具目录，专项接管、规则下发、TCL 策略、HOME 代理和旧记录恢复按[电脑 AI 适配规则与恢复](../../docs/DEVICE_ADAPTATION.zh-CN.md)执行。先检查 APK 能力，再选有限路线；普通接管不默认禁用原桌面。
